# Round 35 · 自测结束「错题再练」

**对应需求**：P1 · 自测结束错题再练  
**前置**：自测结束页（§8）；R18～R34 五档 + R32 题池；本场答错列表  
**原则**：本场错题再测一轮就走；不新建错词引擎；空错则只给「回学习」

---

## 1. 目标与成功标准

自测全部做完后，若本场有答错，结束页提供一键**错题再练**（仅本场错词、当前档）；再练结束后回到正常结束页。  
成功：有错可见按钮；无错不展示；再练题型=进入结束页前的档；窄窗双 CTA 不挤爆；深浅色可读。

---

## 2. 信息架构

| 位置 | 行为 |
|------|------|
| 自测结束页 | 主区：得分/对错摘要（沿用现）；主按钮「回学习」；次按钮「错题再练」（仅本场 wrongCount>0） |
| 再练进行中 | 顶栏可显示弱标签「错题再练 · N」；题型锁定为进入前档；题池=本场错词（不受「只测错词」Chip 影响，本场列表优先） |
| 再练结束 | 仍用结束页；若又有错可再点（允许连环）；「回学习」退出自测 |

```
┌ 自测结束 ─────────────┐
│ 本场 8/10             │
│ 错 2 个               │
│ [错题再练]            │  ← 次要 / Outlined
│ [回学习]              │  ← 主
└───────────────────────┘
```

---

## 3. 题池与规则

- **本场错词**：本轮自测（含再练前那一轮）判错的 wordId 去重列表；答对移出本场列表，不强制改 ProgressStore 错词本语义（进出规则仍跟现自测答对/答错）。  
- **再练抽题**：顺序建议错词出现序或字典序（实现任选，须稳定）；题量=列表长度，可不设上限截断（通常 ≤10～20）。  
- **档**：再练使用进入结束页时的 `quiz_variant`（义/词/听/写/默），界面不提供切档（避免跑题）。  
- **空列表**：不显示「错题再练」。

---

## 4. 主流程

1. 正常自测结束 → 结束页。  
2. 有错 → 点「错题再练」→ 仅用本场错词出题。  
3. 做完 → 再进结束页（摘要为再练场次）；可再练或回学习。  
4. 点「回学习」→ 回学习 Tab / 认读（与现结束页一致）。

---

## 5. 视觉 · 窄窗 / 全屏 / 深浅色

- 「回学习」Filled 主按钮；「错题再练」Outlined / Text，**勿**两主同权。  
- 窄窗两按钮纵向排列，padding ≥14；宽窗可横向但主按钮仍更醒目。  
- 对齐 §8 结束页呼吸感；无新 Banner、无彩带。  
- 深浅色对比足够。

---

## 7. 边界与空态

| 态 | 表现 |
|----|------|
| 本场全对 | 无「错题再练」，仅「回学习」 |
| 再练中途返回 | 允许 AppBar 返回结束页或学习（与现自测返回一致，勿丢进度崩溃） |
| TTS 听/默档 | 再练同样受语音包限制 |
