# Round 36 · 沪教牛津 2024 七年级上（六三）正确词表

**对应需求**：用户确认「课本不对」→ 要 **沪教牛津英语·七年级上 2024（六三学制 Unit1–8）**，不是人教版、也不是现有 `hj-jh-7` 精选。  
**前置**：`Word`/`WordBook` 已支持 `unit`；catalog + assets/wordbooks；学习页单元筛选（**紧凑选择器 UI 另轨修**，本轮不抢）。  
**原则**：先上可校验的正确词书骨架与来源说明；草稿不全不上架为默认；对照课本后再升「可学」。

## 1. 目标与成功标准

孩子能在词书列表选到 **「沪教牛津 · 七年级上（2024）」**，按 Unit1–8 学，词量与单元划分接近课本词汇表（目标约 **330–340** 条，参考 Quizlet「总词汇表全」337）。  
成功：catalog 有正式条目；每词有 unit；含义非空；来源/校验备注可读；旧 `hj-jh-7`（73 精选无真实 unit）保留但标题标明「精选·非七上全书」。

## 5. 本轮范围（做）

1. 将草稿补全到 **接近 337**：补 U4/U5/U8 含义 + 缺词；对照至少两个公开源交叉（英语朗读宝 / Quizlet 总表 / 教习网默写表），并注明「最终以纸质课本词汇表为准」。

6. UI：词书列表能看见新书；切书后学习页单元为 Unit1–8（**单元条交互抛光不在本轮**，见并行 bugfix）。
