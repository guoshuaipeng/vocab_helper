# 开发规则（≤15）

1. UI 文案默认简体中文。
2. 一项一 commit；只本地提交，发版或用户要求才 push。
3. 测试不够时先砍功能不砍测试。
4. 用户报的 bug 插队。
5. 每轮目标约 30 分钟，超过 40 分钟砍未做项。
6. 设计师验收：全屏与窄窗、深浅色都要过。
7. 复盘写入 docs/retro.md；通用规则升到本文件。
8. 优先用项目主题与间距，不随意硬编码颜色。
9. 本产品在用户本机开发，不使用 Cursor 云端代理（除非用户再要求）。
10. 依赖变更写进同一功能 commit。
11. 单词 id 用「词书id-序号」前缀，便于按词书清理进度。
12. Windows 编带原生插件的包前确认工具链（如 nuget）。
13. 每轮开始先读 docs/requirements.md；新需求写入该文件并勾选完成项。
