# Round 34 · 自测变体「听写」

**对应需求**：P1 · 听写自测（听音后默写）  
**前置**：R22 听音选义；R26 拼写默写；R31 四档 Segmented；`quiz_variant`；TTS / FakeWordSpeaker  
**原则**：听写 = 听 + 写，判分前不露拼写；窄窗第五档用单字「默」；不新开引擎

---

## 1. 目标与成功标准

自测增加第五档**听写**：先听英文发音，再输入拼写；与「听」（四选义）、「写」（看中文写英文）并列。  
成功：自动朗读（可再听）；输入区在判分前看不到正确答案；大小写不敏感；空提交不判错；窄窗五档不溢出；深浅色可读。

---

## 2. 信息架构

| 位置 | 行为 |
|------|------|
| 自测顶栏 Segmented | 五档：**义 \| 词 \| 听 \| 写 \| 默**（默 = 听写；`quiz_variant` 增 `dictation` / 听写） |
| 题池 Chip | 沿用 R32「全部词 / 只测错词」；听写可用 |
| 今日任务 | **不改**（仍认读 / 自测入口） |
| 我的 · 自测卡副文案 | 点明含听写（顺带一句即可） |

```
┌ 自测 ──────────────────┐
│ [义][词][听][写][默]    │
│ (全部词) (只测错词)     │
│  🔊 再听               │  ← 无英文拼写
│  [________] 提交       │
└────────────────────────┘
```

---

## 3. 题型规则

- **题干**：不显示英文拼写、不显示中文义（可选极弱提示「听写」标签）；主视觉为喇叭 +「再听」。  
- **入题**：进入本题自动朗读一次（尊重自动朗读偏好；关则仅手动再听）。  
- **作答**：单行 TextField；提交后大小写不敏感比对 `word`；trim 空格。  
- **空提交**：不判错、不进错词、焦点留输入框（同 R26）。  
- **对/错反馈**：对 → 短暂对勾 + 露出拼写；错 → 显示正确拼写 + 可再听；错词进出规则同现自测。  
- **TTS 不可用 / 无语音包**：本档 disabled 或点按 SnackBar 指引（对齐口音卡），勿静默无声出题。

---

## 4. 主流程

1. 切到「默」→ 抽题 → 自动朗读（可）→ 等待输入。  
2. 点「再听」可重复朗读，不重置输入。  
3. 提交 → 判分 → 下一题 / 结束页（结束页沿用 §8）。  
4. 切换档或题池 → 当前题作废重抽（与现变体一致）。

---

## 5. 视觉 · 窄窗 / 全屏 / 深浅色

- 窄窗五档用**单字**标签，禁止折成两行挤掉题干；必要时略减 segment padding，勿小于可读触控。  
- 宽窗可显示「听写」全称。  
- 喇叭与输入框热区分离；主按钮「提交」底栏 padding ≥14。  
- primaryContainer 轻反馈；禁止彩带循环动画。  
- 深浅色对比足够；禁用态对齐 me-disabled。

## 7. 边界与空态

| 态 | 表现 |
|----|------|
| 词书空 / 题池空 | 同现自测空态 |
| 只测错词且无错词 | R32 SnackBar，不进入听写作答 |
| 多词短语 | 整串比对（与写档一致）；不做分词 |
| 切换口音 | 再听用当前口音 |
