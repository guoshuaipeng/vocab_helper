# Round 18 · 自测「看中文选英文」交互与视觉设计

**对应需求**：`docs/requirements.md` · Round 18  
**原则**：一题一屏、大触控、自测≠认读达标；错词本自动进出

---

## 1. 目标与成功标准

学完本单元闪卡后，孩子能用「看中文选英文」测出不会的词，错词进错词本，对过的错词可移出。

成功：能完成一轮自测；结束页看到正确率；错词本数量与判分一致。

---

## 2. 信息架构 / 入口

| 入口 | 行为 |
|------|------|
| 学习页 `认读 \| 自测` | 非错词复习时显示；点「自测」打开自测（有单元筛→当前单元，否则全书） |
| 学习页 AppBar 测验图标 | 同上 |
| 我的 · 自测本词书 | `QuizMode.book` |
| 我的 · 自测当前单元 | `QuizMode.unit`；无单元时禁用+提示 |
| 我的 · 自测错词 | `QuizMode.wrong`（附加入口） |

```
┌ 学习 ─────────────────────┐
│ 词书名                      │
│ [认读|自测]  单元 Chip…     │
│ 闪卡 /（点自测→全屏 Quiz）  │
└─────────────────────────────┘
```

---

## 3. 主流程

1. 进入自测 → 按作用域组卷（`QuizEngine.buildSession`，题量 capped by dailyGoal）
2. 题干中文；4 个英文纵向大按钮；每行旁独立喇叭（与整行选择分离）
3. 点选后锁定；对→浅绿反馈 + `removeWrong` + `bumpTodayCount`；错→标红 + 正解文案 + `markWrong`
4. 「下一题」→ 结束页：答对/答错/正确率；可再测一轮

不自动 `markLearned`（自测答对 ≠ 闪卡「认识」）。

## 5. 实现要点

- `QuizEngine`：同单元干扰优先，不足从全书补；纯函数可测
- `QuizScreen`：独立路由；`seedQuestions` 仅测试
- `ProgressStore.bumpTodayCount`：答对计今日，不写入已学

## 6. 明确不做

听音选义、默写、限时、排行榜；不编造 pep-ps-3 小学课名。

## 7. 验收

- analyze 干净；出题单测 + widget 判分/错词/今日计数
- 窄窗选项可点；词池 &lt;4 时 2～3 选项仍可用
