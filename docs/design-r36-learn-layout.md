# Round · 学习页布局抛光（词卡为主角）

**触发**：用户反馈中间学习区太小，顶部仪表盘像 MVP。  
**前置**：单元点选面板（`1626625`）；ux-guidelines「主角清晰 / 禁止仪表盘墙」。  
**不碰**：词书资产、沪教词表 R36 数据轨、记忆曲线 / OCR。

---

## 1. 目标

认读进行中时，**词卡 + 认识/不认识** 占 AppBar 下内容区约 **≥55%** 竖向空间（窄竖屏手机优先）。  
成功：不再像「上半仪表盘 + 下半小卡片」；窄竖屏一眼看到单词；宽/横屏不拉成瘦长手机。

---

## 2. 信息架构（进行中）

| 区域 | 竖屏手机（主目标） | 宽/横屏（≥700 宽或 landscape 且宽≥600） |
|------|-------------------|----------------------------------------|
| 书名 + 今日进度 | 同一行，次要字号 | 同左，左右 padding 加大 |
| 今日任务三入口 | **单行紧凑**图标+短标题（保留 keys） | 同左，可略宽 |
| 认读\|自测 Segmented | **去掉**（自测入口已在三入口） | 同左 |
| 进度文案 + 单元 | **同一行**（左文案 / 右芯片） | 同左 |
| 词卡 | `Expanded` 主导；字号加大 | 左栏 flex≈3 |
| CTA | 卡下横排 | **右栏竖排**，不拉扁词卡 |

空态 / 加载 / 错词空：仍可保留完整提示，不强制塞仪表盘。

## 4. 视觉与交互

- 去掉进行中「暂无错词」脚注文案墙；弱提示留在复习按钮 Tooltip / subtitle。
- 词面字号竖屏约 44–48；音标次要色；卡内少 chrome。
- 单元仍用 ActionChip + sheet（不回横滑全列）。
- 动效保持现有 150–200ms；不改 flash / press scale。
- 主列：窄 `maxWidth: 520`；宽布局内容可至 ~900，左右留白，避免全宽拉伸。

## 5. 验收

- [ ] 窄竖屏浅/深：词卡明显高于旧截图；无 overflow
