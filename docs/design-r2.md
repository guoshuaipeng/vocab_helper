# Round 2 设计说明（产品 / 交互）

## 目标
- 支持多教材版本与年级选择（含沪教版）
- 首次进入先选型，再学习；词书页可随时更换

## 交互
1. 启动：若未选词书 → 全屏「选择教材与年级」
2. 步骤：先点版本 Chip，再点年级卡片（展示词数），点「开始学习」
3. 学习页标题展示当前词书名 + 剩余进度
4. 词书页：按版本分组列表；主按钮「更换教材/年级」；当前词书打勾
5. 深浅色沿用系统主题

## 文案
- 版本名：人教版PEP / 外研版 / 沪教版 / 人教版初中
- 年级卡片副标题：标题 +「共 N 词」

## 范围外（下轮）
- 按单元筛选、沪教八/九年级全书、发音
