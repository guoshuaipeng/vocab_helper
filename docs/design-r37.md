# Round 37 · 拍照识词（iOS 优先）→ 确认 → 自选/新建单元 → 加入学习

**对应需求**：用户要「拍照识别单词 → 自定义当前单词属于哪一单元 → 再学习」。  
**前置**：词书/单元模型（R36 沪教词表更佳但不强拦）；ProgressStore；学习页单元筛选。  
**原则**：端侧 OCR、先 iOS；识别结果必须人工确认后再入库；不做云同步账号。

---

## 1. 目标与成功标准

在 **iOS** 上拍课本页（或相册选图）→ 用 **Apple Vision** 端侧识别英文词 → 对照当前词书打分/匹配 → 用户勾选要学的词并指定/新建单元 → 写入当前词书可学池（或「我的自定义」附属表）并能在学习/自测里出现。  
成功：无网可完成 OCR；错识可改；单元可自定；Android 本轮不做（留 ML Kit 备注）。

---

## 2. 平台策略

| 平台 | 本轮 | 技术 |
|------|------|------|
| **iOS** | **先做** | `image_picker` / 相机 + **Vision**（VNRecognizeTextRequest）on-device，不传云 |
| Android | 后置 | Google **ML Kit** Text Recognition（另开轮） |
| Windows 桌面 | 非本轮主路径 | 可文件选图；OCR 引擎另议，不挡 iOS |

---

## 3. 主流程

1. 入口：学习页或我的 · 「拍照加词」（仅 iOS 显示相机；他端可灰或「即将支持」）。  
2. 拍照 / 选图 → Vision OCR → 抽出拉丁词（过滤过短、纯数字）。  
3. 结果列表：词 · 可选义（若词书命中则带 meaning）· 匹配态（已在书 / 疑似 / 新词）。  
4. 用户多选 → 选已有 Unit 或「新建单元」命名 → 确认加入。  
5. 新词：允许手改 spelling / 填中文义（空义不可学或进「待补义」桶——实现时二选一，默认 **要求义非空才入学习队列**）。  
6. 加入后 SnackBar「已加入 Unit N · k 个词」；可去学习页该单元。

---

## 4. 与当前词书的关系

- **优先**写入当前选中词书的运行时扩展层（prefs/本地 json overlay），不直接改 assets 只读包。  
- 匹配：大小写不敏感；短语可整词匹配。  
- 已在书中的词：默认勾选「标到某单元」若原 unit 空或用户要改归类（可选，本轮可只支持「新词加入」）。

---

## 5. 不做

账号云盘同步 OCR 图、服务端识别、自动全页入库无确认、Android ML Kit（下轮）、Windows 主交付、付费扫描 App 集成。

---

## 6. 验收（iOS）

- [ ] 无网拍照/选图能出英文候选列表  
- [ ] 确认前可改词/义/单元；取消不写入  
- [ ] 加入后学习页该单元可见  
- [ ] 截图：相机入口、识别列表、选单元确认（浅色至少）  
- [ ] 单测：OCR 文本 → 词抽取纯函数；匹配当前书打分
