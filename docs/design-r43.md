# Round 43 · 学习页眼前一亮大改（focused study session）

**对应需求 / PRD**：[prd-learn-wow.md](prd-learn-wow.md)（ChatPRD ai-development-brief）  
**排期**：**R42 后立刻**（R42 进行中时本轮只备文档，不打断实现）  
**原则**：一屏一任务；单词绝对主角；次要入口折叠；动效表达状态而非装饰  
**参考（公开模式，无付费 URL）**：Duolingo 式单任务顶进度；Quizlet 式大卡揭晓；Anki 式二元判断。  
**工具**：免费 ChatPRD 模板 + Impeccable / frontend-design 思路；**禁用**付费 Mobbin/Refero MCP。

## 0. 方向锁（不可漂）

| 要 | 不要 |
|----|------|
| 大号 **展示级** 英文词为英雄（无装饰衬线换字皮肤） | 奶油底装饰衬线、单词艺术海报风 |

## 1. 目标与成功标准

认读进行中时，孩子 1 秒内只看到「这个词」和「两个判断按钮」；完成一答有清晰交接动画。  
成功：竖屏分区达标；无 chip dump；自测/复习仍可达；SRS 行为不变；截图对比旧版层级明显更强。

---

## 2. 信息架构 / 入口

| 区域 | 竖屏手机 | 宽 / 横屏（≥700 或 landscape 且宽≥600） |
|------|----------|----------------------------------------|
| 顶 chrome | ≤15%：细线性进度 + 极弱书名/计数；可选 R42 弱提示缩成单行 | 同左，左右加 padding |
| 词卡 | ≥55%：纸卡居中；词英雄 → 音标 →「点按看中文」 | **左栏** flex 主 |
| CTA | ≥18%：底双胶囊横排 | **右栏**竖排两大胶囊，不拉扁卡 |
| 次要 | AppBar … 或卡下极弱「更多」→ sheet：学新词 / 复习错词 / 自测各档 / 单元筛选 | 同左 |

书/单元筛选：**保留入口**，放进 sheet 或顶栏溢出，不回横滑芯片列。

## 3. 主流程

1. 进入认读队列 → 卡 slide/fade 入。  
2. 可选：点喇叭朗读（热区 ≠ 翻卡中心）。  
3. 点卡 → 释义揭示（高度扩展或淡入，Quizlet 感）。  
4. 点「认识」或「不认识」→ CTA scale → 卡向侧向 slide 出（认识偏右/上、不认识偏左，提案）→ 写 SRS → 下一词入。  
5. 要换模式 → overflow → 既有流程。

`mermaid
flowchart TD
  A[进入认读] --> B[大词卡展示]
  B --> C{点卡揭晓?}
  C -->|是| D[释义可见]
  C -->|否| E[双 CTA]
  D --> E
  E --> F{认识 / 不认识}
  F --> G[卡 slide 离场]
  G --> H[SRS 更新]
  H --> B
`

## 5. 视觉

- **色**：继续 AppTheme.seed = #4F8CFF + ColorScheme；纸卡用 surface / surfaceContainerLow；**禁止**紫靛渐变皮肤。  
- **卡**：圆角 20–24；**极低**阴影或 1px 边界营造纸感；内边距宽松（≥24）。  
- **词**：展示级字重（Bold/ExtraBold），竖屏目标约 48±8sp；音标 onSurfaceVariant。  
- **CTA**：全宽半栏肥胶囊；「认识」用 primary 实心；「不认识」用 outline / secondary 空心或浅底（提案）；竖向 padding ≥14；圆角 pill。  
- **进度**：LinearProgressIndicator 高 3–4；无大数字仪表盘。  
- **Keys（提案）**：learn_wow_card、learn_wow_word、learn_wow_reveal_hint、learn_wow_meaning、learn_cta_know、learn_cta_unknown、learn_overflow_menu、learn_progress_thin

## 6. 动效（200–300ms）

| 事件 | 动效 |
|------|------|
| 新词入场 | fade + 轻微上移或从对侧 slide in |
| 揭晓释义 | 200ms fade/size；无弹跳 |
| 按下 CTA | scale ≈0.96–0.98；可选 light haptic |
| 答后离场 | **主：水平 slide + fade**（~250ms）；加分：3D flip |
| 成功微反馈 | 顶进度条瞬时走一格；禁止全屏彩带动画 |
