# Round 31 · 自测变体「看词选义」

**对应需求**：P1 · 看词选义自测  
**前置**：R18 QuizEngine / QuizScreen；R22/R26 `quiz_variant` Segmented（看义|听音|拼写）  
**原则**：补齐「看见英文 → 选中文义」；与看义选词成对，防只会中文选英文、见词却不识义

---

## 1. 目标与成功标准

自测增加第四档：**看词选义**——题干为英文单词，四选一中文义；判分前不露正确义项以外的剧透。  
成功：窄窗四档 Segmented 不溢出；答错进错词、答对可出本（沿用现规则）；听音/拼写逻辑不回归。

---

## 2. 信息架构

| 控件 | 行为 |
|------|------|
| 自测顶栏 Segmented | 四档短标：**义** \| **词** \| **听** \| **写**（全称见文案表；窄窗只用一字） |
| 默认档 | 保持上次 `quiz_variant`；若无存档仍默认「义」 |

不做第五档、不做独立「看词」入口页。

```
┌ 自测 ──────────────┐
│ [义][词][听][写]    │
│                    │
│     apple          │  ← 英文题干（大字）
│                    │
│  ○ 苹果  ○ 书本    │
│  ○ 桌子  ○ 水      │
└────────────────────┘
```

---

## 3. 题目规则

- 题干：目标词 `word`（≥28～40sp）；**不**显示 phonetic/example（自测区保持干净，对齐 R21「自测不展示」）。  
- 选项：4 个中文 `meaning`；1 正 + 3 干扰（同书随机；缺 meaning 的词不进本题干池，或干扰跳过无义词）。  
- 判分前：不高亮正确项；不朗读正确答案义。  
- 可选：题干旁小喇叭朗读该英文（与认读一致）；失败则静默，不挡作答。  
- 对错反馈、进错词/出本、结束页：与 R18 同一套。

---

## 4. 主流程

1. 选「词」档 → 重建本轮题库（当前筛选范围：全书或单元，与现自测一致）。  
2. 出题：英文 + 四中文义。  
3. 点选项 → 对错反馈 → 下一题 / 结果。  
4. 切档（义/听/写）行为与现网一致：确认或直接切（沿用现交互，本轮不改切档对话框策略）。

---

## 5. 视觉 · 窄窗 / 全屏 / 深浅色

- 四档 Segmented：窄窗 ≤400 用单字「义词听写」，高度与触控 ≥40；禁止折成两行挤闪卡。  
- 题干英文居中，为视觉重心（§8）；选项区次之。  
- 深浅色对比足够；无新 Banner。

---

## 6. 文案

| 键 | 文案 |
|----|------|
| 档·短 | 义 / 词 / 听 / 写 |
| 档·长（Tooltip/语义） | 看义选词 / 看词选义 / 听音选义 / 拼写默写 |
| 空池 | 没有可测的词（或「本单元暂时测不了」） |
| 我的页自测副文案 | 更新为点明四档：看义 / 看词 / 听音 / 拼写（顺带改一口语句，勿扩入口） |

---

## 7. 边界与空态

| 态 | 表现 |
|----|------|
| 可作干词 < 4（难凑干扰） | 尽量同书抽；不足则放宽到全书已加载词；仍不足 → 该题跳过或禁用本档并 SnackBar「词太少，换看义试试」 |
| 无当前词书 | 与现自测一致 |
| TTS 失败 | 不影响看词档（喇叭可藏或灰） |
