## 5. 推荐下一轮（Top 1–3）

### R44（推荐立刻 · RICE #1+#2）

- **主题**：自测页视觉对齐学习页（focused quiz chrome）+ 学习喇叭高对比小抛光。  
- **成功**：孩子从 overflow 进自测后，仍感到「同一个单词小助手」；五档与引擎行为零回归。  
- **设计**：见 [design-r44.md](design-r44.md)（若同期提交）。  
- **本分析轮**：只落文档；**不写功能代码**。

### R45（建议）

- **首选 B03** 错词本→自测一键闭环；若跟课换单元投诉多则改 **B04**。  
- 保持 ≤0.5–1 人日；不改 SRS。

### R46（建议）

- **B05** 我的页信息层级；或纸质到位时 **B07** 补词插队（内容轮可压过 UI）。  
- Vision / Android 仅在设备条件具备时插队，不挡 R44–R45。

## 6. 风险与技术约束

| 风险 / 约束 | 应对 |
|-------------|------|
| SharedPreferences 单测污染（R32/R40/R42 教训） | 一文件一测或单 `testWidgets` 多场景；勿中途 `setMockInitialValues` |
| 截图 Material 图标空方块 | Soft-pass 图标字形；**对比度/色**须截图可辨；喇叭项以对比为准 |
| 自测顶栏控件多，硬砍易丢档位发现性 | 降权/紧凑，**不删除**五档与题池 |
| 禁止改 QuizEngine / 新题型（R44） | 只动 chrome；行为单测回归 |
| 补词无纸质易误 | B07 Confidence 压低；无权威源不升「进行中」 |
| Android SDK / iOS 真机依赖环境 | B09/B11/B12 单列，不占无设备轮次 |
| 付费调研 / 云代理 | **禁用**；公开模式散文引用即可 |
| 时间盒 | 轮次 ~30min；>40min 先砍范围不砍测试 |
