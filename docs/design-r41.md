# Round 41 · 词书列表推荐本置顶

**对应需求**：P1 · R40 跟课可见性补齐  
**前置**：R40 `recommendedBookId` / 「推荐」标签  
**原则**：推荐跟课不用滚半页才看见；不拆乱原版本分组其余顺序

---

## 1. 目标

词书页（Books）打开时，**首屏即可看到**推荐本「沪教牛津 · 七年级上（2024）」；其下仍按版本分组列出其余词书（推荐本不在原分组重复出现）。

成功：新用户/想换课的人进「词书」立刻看到推荐卡，一点即切。

```
脚注
```

## 3. 规则

| 态 | 行为 |
|----|------|
| catalog 含 recommendedBookId | 列表顶部「推荐跟课」标题 + 该卡（保留「推荐」subtitle / key） |
| catalog 无推荐 id | 不显示置顶块；行为同 R40 前 |
| 推荐本已是当前选中 | 卡仍置顶，选中高亮不变 |
| 原 version 分组 | `booksOf` 结果中 **过滤掉** recommended id，避免重复；过滤后空则跳过该 version 标题 |

不做：改 Setup 布局、强推 Dialog、排序其它书、删除精选书。
