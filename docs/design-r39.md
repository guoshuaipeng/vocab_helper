# Round 39 · 错词本可浏览清单

**对应需求**：P1 · 错词本可浏览清单  
**前置**：ProgressStore `wrong_ids`；我的页错词卡（数字 + 复习/测/清空）；R29 到期复习 sheet 交互范式；R16/R32 复习错词与只测错词  
**原则**：把错词从「一个数字」变成「可看、可开干」；不改进出错词规则；复用现有复习/自测入口

---

## 1. 目标与成功标准

孩子/家长从「我的 · 错词本」能点开，看清**当前词书**里有哪些错词（词+义），并一键去认读复习或自测错词。  
成功：有错可见列表；空态有下一步；主 CTA 进现有「复习全部错词」；次 CTA「去测错词」；窄窗可滚完；深浅色可读。

---

## 2. 信息架构

| 入口 | 行为 |
|------|------|
| 我的 · 错词本卡 · 数字行 / 「查看错词 ›」 | 整行可点（InkWell）；有错 chevron；0 仍可点进空态 |
| 学习页今日任务「复习错词」 | **本轮不改**（仍直接进认读错词模式） |
| 自测 Chip「只测错词」 | **本轮不改** |

不做独立 Tab、错词强度排序、跨词书合并清单、手势滑动删除。

```
┌ 我的 · 错词本 ─────────┐
│ 错词本                 │
│ 6                 ›    │  ← 可点
│ [复习全部] [测] [清空] │
└────────────────────────┘
          ↓
┌ 错词本 ────────────────┐
│ apple — 苹果    Unit 2 │
│ book  — 书      Unit 1 │
│ …                      │
│ [去测错词]             │  ← 次 / Outlined
│ [复习这些错词]         │  ← 主
└────────────────────────┘
```

---

## 3. 列表规则

- **范围**：仅当前词书 `wrongIds` ∩ 本书词条；无当前词书 → 入口 disabled（与导出一致）。  
- **排序**：按 `word` 字典序（稳定；不按加入时间，避免改存储）。  
- **行**：`word`（略重）+ `meaning`（空义不渲染义）；若有 `unit` 右侧弱 Chip/次要字「Unit N」。  
- **截断**：超过 40 条只显示前 40 + 脚注「还有 M 个，复习/自测仍会带上全部错词」。  
- **不**在本轮做「点行翻卡详情」；整表靠底栏 CTA。

---

## 4. 主流程

1. 点错词数字行 /「查看错词」→ 底部 sheet（首选，对齐 R29）：标题「错词本」。  
2. 加载列表；空 → 「暂无错词」+「去学新词」（pop 后切学习·学新词，能则直接切）。  
3. 有词 → 主按钮「复习这些错词」（Filled，≥14 竖向 padding）→ 关 sheet → 走现有 `onReviewWrong`（全书错词认读）。  
4. 次按钮「去测错词」（Outlined）→ 关 sheet → 走现有「去测错词」（只测错词池，档沿用当前 quiz_variant）。  
5. Sheet **内**不放「清空」（清空仍在卡上，防误触）。  
6. 若学习页已选单元：sheet 脚注一行弱提示「学习页已筛选 · {unit}；点复习仍是全部错词。要用单元请回卡上点『只复习…』」——**不**在 sheet 内再做单元切换（砍范围）。

---

## 5. 视觉 · 窄窗 / 全屏 / 深浅色

- Sheet：`maxHeight` ≈ 70% 屏高；列表可滚；双 CTA sticky 底，主次分明（勿两主同权）。  
- 行高 ≥48；正文 ≥16sp；对齐 R29 到期行。  
- 入口有数时数字/行可用 primary 弱强调；0 用 onSurfaceVariant。  
- 深浅色对比足够；无新 Banner、无贴纸 Badge、无彩带。  
- 截图须含 sheet 本体（MaterialApp.builder 包 overlay，承接 R28/R29 教训）。

## 7. 边界与空态

| 态 | 表现 |
|----|------|
| 无当前词书 | 入口不可点 / 「先选一本词书」 |
| 错词 0 | 可进空态 sheet +「去学新词」 |
| 错词 >40 | 截断 + 脚注；CTA 仍作用于全部错词 |
| 词条已从词书删除但仍在 wrong_ids | 跳过该 id，不崩溃（列表只显示能解析的词） |
| 清空错词后 | 再开 sheet 应为空（以 store 为准） |
