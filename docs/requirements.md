# 产品需求（单一来源）

> **所有人（含自动化迭代助手）读本仓库时，以本文件为准了解「接下来要做什么」。**  
> 路径：`docs/requirements.md`  
> 完成一项就勾选；新需求追加到对应优先级；大改动在「变更记录」留一行。  
> **未写 `docs/design-rN.md` 的主需求，不进入开发。** 设计方案须含：目标用户行为、信息架构、主流程、关键态、窄窗/全屏、文案、验收。

## 角色分工

| 角色 | Bot | 负责 |
|------|-----|------|
| 产品 + 设计 | **单词产品设计** | 写/改本文件与 `design-rN.md`、`ux-guidelines.md`；定范围、验收、排期；bug 插队条目 |
| 开发迭代 | **单词迭代** | 只按本文件 + 对应设计稿：开发 → 测试 → 设计师验收 → 复盘；不自创主需求 |

用户新想法先跟「单词产品设计」说；落地后「单词迭代」从「进行中」取项实现，不要每轮问是否继续。

## 怎么用

1. **产品/设计**：新需求或改范围 → 更新本文件 → 补 `design-rN.md` → 标「可开发」后交给迭代。
2. **排期 / 迭代**：每轮先打开本文件，从「进行中」取 1 个主需求 + 可选 1 个小抛光。
3. **实现后**：把对应条目改成 `[x]`；细节以当轮 `design-rN.md` 为准。
4. **用户新提需求**：先追加到本文件，再补设计稿，不要只写在聊天里。
5. **与其它文档**：`design-rN.md` = 交互+视觉；`retro.md` = 复盘；`ux-guidelines.md` = 持续设计约定；`backlog.md` = 历史镜像。

### Round 18 · 自测「看中文选英文」（四选一）

**设计稿**：[`docs/design-r18.md`](design-r18.md)（必读后再开发）

**用户故事**  
作为小学生/初中生，学完本单元闪卡后，我想用「看中文选英文」测一下，好知道哪些词其实不会，并自动进错词本。

**范围（做）**

- [x] 学习页模式切换：**认读 | 自测**（错词复习模式不显示自测）
- [x] 我的页次要入口：**自测本词书**、**自测当前单元**（无单元时后者禁用+提示）；另附「自测错词」
- [x] 题型：题干=中文 `meaning`；4 个英文选项（1 正解 + 最多 3 个同作用域干扰项；不足则跨单元同书补齐）
- [x] 判分与错词：错 → `markWrong`；对且在错词本 → `removeWrong`；对不自动记「已学」（自测≠认读达标）
- [x] 今日计数：自测答对计入 `todayCount`（`bumpTodayCount`）；答错不计入
- [x] 一题一屏；选后锁定选项；对/错反馈；「下一题」；结束页显示正确率
- [x] 选项旁可点喇叭朗读该选项英文（防误触：喇叭与整行选择区分）

**范围（不做）**

- 听音选义、拼写默写、限时、连错惩罚、排行榜
- 改底部 Tab 结构、新账号体系

**验收**

- [x] 全屏 ≥900px 宽、窄窗 ≤400px、深/浅色：选项可点、无横向溢出（纵向大按钮+独立 Scaffold）
- [x] 作用域：本单元 / 全书 / 错词子集，题目数量与筛选一致
- [x] 干扰项不与正解相同；单词池 &lt;4 时降级为 2～3 选项并仍可用
- [x] 至少：出题纯函数单测 + 1 个 widget 测选对/选错与错词联动

**同轮小抛光（可选）**

- [x] 学习页单元 Chip 已横向滚动（本轮跳过）
