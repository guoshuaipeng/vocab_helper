# 单词小助手 · 持续设计约定

产品、教育、UI/交互共用。写需求或 `design-rN.md` 时按此打磨；开发按设计验收。

---

## 1. 需求怎样算「打磨好」

一条主需求必须能回答：

1. **谁**在什么场景下用？（年级/家长旁观？）  
2. **完成什么行为**算成功？（可观察，不要「提升体验」）  
3. **做 / 不做**边界各至少 3 条  
4. **入口在哪**、和现有闪卡/错词/单元如何共存  
5. **验收列表**（含窄窗、深浅色、空态）  
6. **设计稿路径** `docs/design-rN.md` 已存在  

未满足以上 6 点 → 只进 P2/备忘，不进「进行中」。

---

## 2. 设计稿最低目录

```
# Round N · 标题
目标与成功标准
信息架构 / 入口
主流程（可用 mermaid 或步骤列表）
线框（窄窗 ASCII 即可）
视觉（组件、间距、色语义、动效）
文案表
边界与空态
验收清单
明确不做
```

不必出高保真；**必须**出线框与文案。

---

## 3. 视觉语言（沿用，勿另起炉灶）

| 项 | 约定 |
|----|------|
| 色 | `AppTheme.seed = #4F8CFF`；深浅色走 `ColorScheme` |
| 卡片 | 圆角 20、elevation 0 |
| 主按钮 | 底部大触控，竖向 padding ≥14 |
| 儿童可读 | 正文关键操作 ≥16sp；题干/单词 ≥28～40sp |
| 布局 | 学习主列 `maxWidth: 520` 居中；禁止首屏堆统计卡片墙 |
| 动效 | 150～200ms；表达状态切换，不做装饰性循环动画 |
| 禁止 | 紫渐变皮肤、贴纸式浮动 Badge、首屏多 Banner |

---

## 4. 教育侧默认立场

1. **跟课单元**优先于随机词表。  
2. **测 > 只刷**：有认读就要有检测入口。  
3. **错词是资产**：选错/不认识要进本；选对/认识可出本。  
4. **假会要防**：认识需能回流（间隔复习）；自测答对不代替认读巩固。  
5. **文案口语**：对学生说「自测/错词/还差 N 个」，不说算法名。
6. **习惯反馈**：周打卡只展示本周哪天达标，强化节奏；不做社交勋章/排行/补打卡。

---

## 5. 交互侧默认立场

1. 一次一个主决策（认或不认 / 选 A～D）。  
2. 破坏性操作要确认（清空进度/错词）。  
3. 喇叭与选择/翻卡热区分离。  
4. 筛选（单元）变更 → 静默重载 + 短 SnackBar，少弹窗。  
5. 空态给下一步按钮，不给空白欣赏。

---

## 6. 迭代节奏

每轮：**读 requirements → 确认/补 design-rN → 开发 → 设计验收 → retro**。  
持续出需求时：先写 requirements 条目骨架，再补设计稿，最后才把条目移入「进行中」。

---

## 7. 听音类自测

1. 题干以喇叭为主，**判分前不露出目标英文拼写**（防看词猜）。  
2. 喇叭与选项热区分离；进题自动读 1 次，允许「再听」。  
3. TTS 失败：禁用听音题型或整轮降级为看义选词，并口语提示；禁止无声干等。

---

## 8. 美感底线（反 MVP 脚手架）

功能验收通过 ≠ 体验验收通过。设计师验收时额外看：

1. **主角清晰**：学习页闪卡/自测题干必须是视觉重心；顶栏控件不得堆成仪表盘。  
2. **每次点按有回声**：翻卡、认识/不认识、选项对错、朗读，都要有 ≤220ms 状态反馈。  
3. **留白是功能**：单词区上下要有呼吸；不要用统计条、Chip、Segmented 把主内容挤到 <40% 屏高。  
4. **儿童向干净**：大触控、口语文案、高对比；禁止紫渐变皮肤、贴纸 Badge、首屏多 Banner。  
5. **空态有下一步**：任何空列表必须带一个主按钮，禁止「空白欣赏」。

不满足以上 → 可对「功能已完成」轮次仍打回体验项，或开体验跃迁轮（见 `design-r25.md`）。

## 9. 设计师验收须截图

功能单测绿 ≠ 视觉通过。交验轮次（及插队抛光）须在 `docs/shots/` 留下：

1. **窄窗 ≤400** × 浅色、深色各至少 1 张关键屏  
2. **全屏/宽窗 ≥900** × 浅色、深色各至少 1 张关键屏  
3. 验收 md 勾选环境项时附文件名；结论「通过/打回」基于截图，不以「代码看起来对」代替

## 10. 拼写默写

1. 判分前不露正确拼写；大小写不敏感；空提交不进错词。
2. 自测答对仍不代替认读巩固（不 markLearned）。
