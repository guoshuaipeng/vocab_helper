# Round 26 · 自测变体「拼写默写」交互与视觉设计

**对应需求**：`docs/requirements.md` · Round 26  
**前置**：R18 看义选词、R22 听音选义；复用 `QuizEngine` / `QuizScreen` / `quiz_variant`  
**原则**：再认之后做**提取**；一题一屏；输入容错明确；不 markLearned

---

## 0. 现状

自测顶栏已有 Segmented：`看义选词 | 听音选义`，偏好键 `quiz_variant`。组卷/错词/今日计数规则以 R18 为准。本轮只加第三题型「拼写」。

---

## 1. 目标与成功标准

看到中文释义（默认）或听完英文后，用键盘输入英文拼写；对错即时反馈；错词进本。  
成功：完成一轮拼写自测；大小写不敏感；正确率可信；窄窗键盘不挡住「检查」主按钮。

---

## 2. 信息架构 / 入口

| 入口 | 行为 |
|------|------|
| 自测顶栏 Segmented | `看义 \| 听音 \| 拼写`（三档；过窄可横滑或缩短文案「看\|听\|写」） |
| 学习页/今日任务「自测」 | 用上次 `quiz_variant`；首次仍默认看义 |
| 我的 · 自测本词书/单元/错词 | 同作用域；题型随偏好 |

不做独立 Tab；不做语音输入/手写板。

```
┌ 自测 ──────────────────┐
│ 题 3/12  [看|听|写]     │
│ 中文题干：苹果           │
│ ┌ 输入框 ─────────────┐ │
│ │ apple_              │ │
│ └─────────────────────┘ │
│ [检查]                  │
└─────────────────────────┘
```

可选：题干旁小喇叭「听提示」（播目标英文）；默认关，避免变成听写听力考。首版：**默认只出示中文 meaning**，喇叭为次要。

---

## 3. 主流程

1. **组卷**：复用 R18 session / 作用域；每题 target 一词。  
2. **题干**：显示 `meaning`；不显示正确拼写。  
3. **输入**：单行 `TextField`，`textCapitalization: none`，`autocorrect: false`，`enableSuggestions: false`；键盘英文优先。  
4. **检查**：点「检查」或键盘 done → 判分。  
5. **判分规则**（trim 后）：  
   - 比较：双方 `trim` + 英文 **大小写不敏感**；首版**不**做编辑距离容错（aple ≠ apple）。  
   - 对：浅绿反馈 + `removeWrong`（若在错词本）+ `bumpTodayCount`；**不** `markLearned`。  
   - 错：标红 + 展示正解 `word` + 中文；`markWrong`；输入框可再改后「再试」或直接「下一题」（实现二选一：**首版锁定后「下一题」**，与 R18 一致）。  
6. **空提交**：Shake/提示「先写出单词」；不判错、不进错词。

---

## 4. 视觉 · 窄窗 / 全屏 / 深浅色

- 输入框高度 ≥ 48；圆角 16；`surfaceContainerHighest` 底。  
- 「检查」Filled，竖向 padding ≥14；与 R25 底栏触控对齐。  
- 窄窗 ≤400：Segmented 可缩文案；输入框在键盘弹出时保证「检查」仍可见（`resizeToAvoidBottomInset` / 滚动）。  
- 全屏 ≥900：题干区居中 maxWidth 520。  
- 深浅色：错误用 `error`，正确用 `primary`/`tertiary` 轻闪 ≤220ms；无紫渐变。
