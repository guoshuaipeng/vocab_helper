# Round 19 · UI 验收清单（提交 单词UI设计）

**实现状态**：代码+测试已提交；开发 + 单测已完成，待设计验收后才能把 requirements 全部勾完并移出「进行中」。  
**对照**：`docs/design-r19.md`、`docs/ux-guidelines.md`

## 环境

- [ ] 窄窗 ≤400px 宽（或 Windows 窗口拉到约 360）
- [ ] 全屏 / 宽窗 ≥900px
- [ ] 浅色主题
- [ ] 深色主题（系统或模拟）

## 布局与视觉

- [ ] 学习页标题下方出现「今日 N/Goal · 连续 X 天」+ 三等分入口，**非**独立 Tab
- [ ] 三入口单行：学新词 / 复习错词 / 自测；窄窗不折成 2×2（字号可略缩）
- [ ] 宽窗内容区约 `maxWidth: 520` 居中，入口不被拉得过宽
- [ ] 入口高度 ≥64、圆角 16；选中项 primaryContainer + 描边；未选中不抢权重
- [ ] 未再包一层整页大 Card / 无统计墙 / 无 Banner
- [ ] 深浅色对比可读（禁用「复习错词」灰色可辨）

## 行为

- [ ] **学新词**：退出错词复习，回到认读闪卡；未达标副文案「还差 N」，达标「加练」
- [ ] **复习错词**：进入**全书**错词闪卡；0 错词时不可点 + Tooltip/「暂无错词」；与「我的·当前单元错词」不冲突
- [ ] **自测**：打开看中文选英文（当前单元优先，无单元则全书）
- [ ] 与下方「认读 | 自测」SegmentedButton 并存时不迷路
