**单测**：flutter test 全绿（47）

## 环境

- [ ] 窄窗 ≤400（7 格单行不换行、无横向溢出）
- [ ] 全屏 / 宽窗 ≥900（勿拉成统计墙；仍嵌在今日目标卡内）
- [ ] 浅色 / 深色（`ColorScheme`；无贴纸 Badge / 紫渐变 / 火焰循环）

## 入口与布局

- [ ] 位置：「我的」今日目标卡片内底部（紧挨进度条；若有 R20「待复习」则在其下、仍属目标卡）
- [ ] 周定义：自然周**周一～周日**；只展示含「今天」的那一周
- [ ] 7 格等分单行；格径 ≥28、热区 ≥40；圆角 20、elevation 0
- [ ] 与「已连续 N 天」并存；不删除今日目标卡或连续天数数字

## 七格状态

- [ ] **达标**：有记录且 count≥goal → 实心 `primary`（可选小勾）
- [ ] **未达标**：有记录且 count&lt;goal → 空心 `outline`
- [ ] **无记录**：过去日无键 → 更浅 `outlineVariant`（**勿伪造达标**）
- [ ] **今日进行中**：今天且未达标 → 描边加粗（可选半填/内点）
- [ ] **未来日**：本周内 &gt; 今天 → 极浅占位，**不可点**
- [ ] 格上不标 count；Tooltip 可选：已达标 / 未达标（N/目标） / 无记录

## 数据口径

- [ ] 某日达标 = `dayCount >= dailyGoal`（同 `todayGoalMet`）
- [ ] 计数来源：`markLearned` / `bumpTodayCount`；改目标**不**重算历史日
- [ ] 按日归档（如 `day_count_yyyy-MM-dd`）；跨日先写昨日再重置今日
- [ ] 连续天数仍用 `streakDays()`，不另算第二套

## 文案与动效

- [ ] 星期：一…日；连续：「已连续 N 天」；区标题可省「本周打卡」
- [ ] 达标填实反馈 150～200ms 一次（若有动画）
- [ ] 文案无 SRS/社交压力；无补打卡入口

## 回归 / 不做项

- [ ] 今日目标进度条 / 改目标 / streak 数字行为未回退
- [ ] **不做**：社交勋章、排行、分享海报、补打卡、月历热力图、年度统计、自定义周起始、搬到学习页首屏
- [ ] 既有 flutter test 绿；单测覆盖跨日归档、周一/周日边界、无历史键
