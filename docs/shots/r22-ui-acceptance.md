# Round 22 · UI 验收（交给「单词UI设计」）

**对应**：`docs/design-r22.md` · 听音选义  
**前置**：R18 看义选词；R21 已通过  
**代码**：听音 UI / `quiz_variant` / TTS 降级已落地（本文件不宣称设计师结论）

## 环境

- [ ] 窄窗 ≤400
- [ ] 全屏 / 宽窗 ≥900（主列 `maxWidth: 520`）
- [ ] 浅色 / 深色

## 入口与题型

- [ ] 自测顶栏 Segmented：`看义选词 | 听音选义`；偏好可记住（`quiz_variant`）
- [ ] 学习页/今日任务「自测」、我的·自测：跟上次题型；首次默认看义
- [ ] 无独立 Tab；口音走全局 WordSpeaker

## 听音题行为

- [ ] 题干：听英文选意思；判分前**不**显示目标拼写
- [ ] 进题自动朗读 1 次；「再听一遍」热区 ≥48，与选项分离
- [ ] 四选一为**中文义**（去重）；词池 <4 时 2～3 选项仍可用
- [ ] 对：浅绿 + removeWrong + bumpTodayCount；错：标红 + 正解 + 再播英文 + markWrong
- [ ] 判分后可显示 `英文 · 中文`；**不** markLearned

## TTS 降级

- [ ] speak 失败：SnackBar「暂时没法朗读，已改为看中文选英文」→ **整轮**切回看义
- [ ] 无英文语音包：禁用听音段 + 提示「请安装系统英文语音包后再用听音」
- [ ] 单测 FakeWordSpeaker 覆盖进题 speak / 降级 / 禁用

## 视觉与文案

- [ ] 选项规格同 R18；题干大喇叭；切题型 ~150ms
- [ ] 文案无 SRS/SM-2；深浅色对比足够；无横向溢出
