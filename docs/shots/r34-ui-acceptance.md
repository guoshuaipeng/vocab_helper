## 听写行为

- [ ] 判分前不露英文拼写、不露中文义；主视觉喇叭 +「再听」
- [ ] 入题自动朗读；「再听」可重复
- [ ] 占位「写出你听到的单词」；主按钮「提交」padding ≥14
- [ ] trim + 大小写不敏感；空提交不判错、不进错词
- [ ] 对：勾 +「拼对了」+ 露出拼写；错：正确答案 + 可再听；错词规则同现自测
- [ ] TTS 不可用：听/默档 disabled 或 SnackBar「没法朗读，先检查系统语音包」
