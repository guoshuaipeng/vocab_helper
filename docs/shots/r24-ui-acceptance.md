## 环境

- [ ] 窄窗 ≤400（搜索框 + 命中行无横向溢出）
- [ ] 全屏 / 宽窗 ≥900（勿堆统计墙；仍在词书 Tab）
- [ ] 浅色 / 深色（`ColorScheme`；圆角 20、elevation 0；对比足够）

## 入口与信息架构

- [x] 词书 Tab 顶栏搜索框；hint「搜索英文或中文释义」
- [x] 命中行：`word` + `meaning · 词书标题`；点行 → 切书确认（同 R13）
- [x] 清空 / 无字 → 退回版本分组词书列表
- [x] **无**独立搜索 Tab；不进学习页首屏

## 索引与查询行为

- [x] catalog 就绪后后台预建跨书索引（复用 `loadBook` / `_cache`）
- [x] 英文小写子串 + 中文释义子串匹配
- [x] 稳定序：当前词书优先 → 版本/年级 → word 字典序 → bookId；截断 **40**
- [x] 索引就绪后同步查询（无每键全库串行扫）；目标 ≤300ms
- [x] 索引未就绪：`LinearProgressIndicator` +「正在准备搜索…」；就绪后同一查询自动重跑
- [x] catalog `reloadCatalog` → 重建索引（会话内内存）

## 视觉 · 文案 · 空态

- [x] 有结果：「找到 N 条（最多显示 40）」
- [x] 无结果：「没有匹配的单词」
- [x] 当前书可识别（check + 轻 primaryContainer）
- [x] 切书文案：切换到这本词书？ / 取消 / 切换
- [x] 同词多书：一书一行；单本 load 失败跳过不崩（单测）
- [x] 命中 Card elevation 0 / 圆角 20；文案口语、不说倒排/哈希

## 回归 / 不做项
