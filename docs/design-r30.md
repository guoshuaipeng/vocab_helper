# Round 30 · 本词书「单元进度」一览

**对应需求**：P1 · 单元进度一览  
**前置**：词条 `unit`；ProgressStore 已学/错词；已有单元筛选  
**原则**：跟课可见——一眼看出各单元学到哪；点单元即复用现有筛选，不另造学习引擎

---

## 1. 目标与成功标准

在「我的」打开当前词书的**按单元进度表**：每单元已学/总词、错词数；点某单元切到该单元筛选并去学习。  
成功：有 unit 的词书列出各单元；无 unit 词书给一句说明；窄窗可滚完；深浅色对比足够。

---

## 2. 信息架构

| 入口 | 行为 |
|------|------|
| 我的页 · 当前词书区 | 次要入口「单元进度」（TextButton / 列表行 + chevron） |
| 无当前词书 | disabled +「先选一本词书」 |

不做独立 Tab、班级对比、勋章通关动画。

```
┌ 我的 ─────────────────┐
│ 今日目标 / 待复习…     │
│ 单元进度  ›            │
└───────────────────────┘
          ↓
┌ 单元进度 · {词书短名} ─┐
│ U1  已学 12/20  错 2  ›│
│ U2  已学  0/18  错 0  ›│
│ …                      │
└────────────────────────┘
```

---

## 3. 列表规则

- 范围：仅**当前词书**；按词条 `unit` 分组（空/缺 unit 归入「未分单元」，有则单独一行置底）。  
- 排序：单元名自然序（尽量按数字：1、2、…10）；「未分单元」最后。  
- 行字段：`单元名` · `已学 a/b` · 错词 `错 c`（c=0 可淡化或不写「错 0」——推荐写「错 0」保持列齐）。  
- 进度条（可选弱视觉）：行下 2～3px track，`a/b` 比例；无动画循环。  
- 截断：单元数不设硬顶（小学册通常 ≤16）；列表可滚。

---

## 4. 主流程

1. 点「单元进度」→ 底部 sheet（首选，maxHeight ~70%）或子页；标题「单元进度」。  
2. 展示各单元行。  
3. 点某一行 → 关闭 sheet → **写入与现有一致的单元筛选**（与学习页单元 Chip 同源）→ 切学习 Tab · 认读；短 SnackBar「已筛选 · {单元名}」（对齐既有切单元提示口径）。  
4. 点「未分单元」（若有）→ 筛选为仅无 unit 词；若产品侧现有筛选不支持「仅空 unit」，本轮改为：SnackBar「这些词在「全部」里看」且切到显示全部（在设计验收注明实际实现）。  
5. Sheet 顶可附一行汇总：`已学 sumA/sumB · 错词 sumC`（只读）。

---

## 5. 视觉 · 窄窗 / 全屏 / 深浅色

- 行触控 ≥48；单元名 ≥16sp；数字用 `onSurfaceVariant`。  
- 已学=总词：弱勾或「满」淡标签（非贴纸 Badge）。  
- 进度条用 `primary` / `surfaceVariant`；深色可读。  
- 入口弱于破坏性「清空」；与「导出进度」同级次要。

## 6. 文案

| 键 | 文案 |
|----|------|
| 入口 | 单元进度 |
| 无书 | 先选一本词书 |
| 标题 | 单元进度 |

| 未分 | 未分单元 |
| 全无 unit | 这本词书还没有按单元划分 |
| 筛选成功 | 已筛选 · {unit} |

---

## 7. 边界与空态

| 态 | 表现 |
|----|------|
| 无当前词书 | 入口不可用 |
| 词书词条全无 unit | Sheet 内一句「这本词书还没有按单元划分」+「关闭」；不假装列表 |
| 某单元 b=0 | 不出现该行 |
| 切词书后 | 重开按新书计算 |
