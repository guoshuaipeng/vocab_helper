# Round 29 · 到期复习清单（待复习可点开）

**对应需求**：P1 · 到期复习清单  
**前置**：R20 ProgressStore `review_at_` / `review_stage_`；我的页「待复习 N」；认读队列已到期优先  
**原则**：把间隔复习从「数字」变成「可看、可开干」；不改 1/3/7 算法

---

## 1. 目标与成功标准

孩子/家长从「我的」看到的「待复习 N」能点开，看清**当前词书**哪些词已到期，并一键进入认读复习。  
成功：列表含词+义；空态有文案；点「开始复习」后学习页认读队列优先这些到期词；窄窗可完成；深浅色可读。

---

## 2. 信息架构

| 入口 | 行为 |
|------|------|
| 我的页 · 「待复习 N」文案/行 | 整行可点（InkWell）；N>0 有 chevron；N=0 仍可点进空态 |
| 今日任务「学新词」副文案「复习 b」 | **本轮不改**（仍靠认读队列；清单只从我的进） |

不做独立 Tab、日历热力图、跨词书合并清单。

```
┌ 我的 ────────────────┐
│ 今日目标…            │
│ 待复习 3  ›          │  ← 可点
│ 周视图…              │
└──────────────────────┘
        ↓
┌ 到期复习 ────────────┐
│ apple — 苹果   复习  │
│ book  — 书     复习  │
│ …                    │
│ [开始复习]           │
└──────────────────────┘
```

---

## 3. 列表内容

- 范围：当前词书、`review_at ≤ today` 的已认识词（与 R20 到期定义一致）。  
- 排序：到期更早的在前；同日按 word 字典序。  
- 行：`word` + `meaning`（空义不渲染义）；右侧弱标签「复习」（对齐闪卡）。  
- 截断：超过 40 条只显示前 40 + 脚注「还有 M 个，开始复习仍会全部入队」。  
- 无当前词书：入口 disabled 或提示「先选一本词书」（与导出一致）。

---

## 4. 主流程

1. 点「待复习 N」→ 底部 sheet（首选）或全屏子页：标题「到期复习」。  
2. 加载到期列表；空 → 插画/短文案「暂无到期复习」+「去学新词」（pop 后切学习·学新词，能则直接切）。  
3. 有词 → 主按钮「开始复习」（底部大触控 ≥14 竖向 padding）。  
4. 点「开始复习」→ 关闭 sheet → 切到学习 Tab · 认读模式；队列 = 到期复习 ∪ 新词（**仍遵循 R20**：到期旧→新再新词；不另开「仅到期」模式，避免两套队列）。  
5. 列表行**本轮不要求**单行点开闪卡（避免半成品详情）；整表靠「开始复习」。

---

## 5. 视觉 · 窄窗 / 全屏 / 深浅色

- Sheet：`maxHeight` ≈ 70% 屏高，列表可滚；主按钮 sticky 底。  
- 行高触控友好 ≥48；正文 ≥16sp；word 略重。  
- 「待复习 N」行：有数时用 primary 系弱强调；0 用 onSurfaceVariant。  
- 深浅色对比足够；无新 Banner、无贴纸 Badge。

---

## 7. 边界与空态

| 态 | 表现 |
|----|------|
| 无当前词书 | 入口不可用 +「先选一本词书」 |
| N=0 | 可进空态 sheet |
| 列表加载中 | 短 CircularProgress 或骨架 3 行 |
| 切词书后 | 清单按新书重算（关闭后重开即可） |
