# Round 40 · 默认推荐沪教牛津2024七上

**对应需求**：P1 · 新装/未选词书时默认跟课课本  
**前置**：R36 `hj-ox-7a-2024` 已上架  
**原则**：减少「打开还是精选旧书」的错觉；不强制覆盖用户已选

---

## 1. 目标

首次打开（无 `selected_book_id`）进入选型页时，**版本与词书已预选**「沪教牛津 · 七年级上（2024）」；词书列表对该本显示「推荐」弱标签。  
成功：新用户一点确认即用对课本；老用户已选其它书不受影响。

## 2. 规则

| 态 | 行为 |
|----|------|
| 无选中词书 | Setup：version=`沪教牛津2024`，book=`hj-ox-7a-2024`（若 catalog 有） |
| 已有选中 | 保持；Setup/Books 仍可改 |
| catalog 缺推荐 id | 回退现有「catalog.first」行为 |
| 词书列表 / Setup 列表 | 推荐本 subtitle 或 Chip 显示「推荐」 |

不做：弹窗强推换书、迁移旧进度、删除精选书。

## 3. 文案

| 键 | 文案 |
|----|------|
| 标签 | 推荐 |
| Setup 顶注（可选一行） | 默认跟课：沪教牛津 2024 七上（可改） |

## 4. 验收

- [x] 清空 selected 后进 Setup：已选中 2024 七上，点确认进入学习
- [x] 已选 pep-ps-3：重启仍是 pep-ps-3（widget keep 测）
- [x] 词书页推荐本可见「推荐」
- [x] 窄/宽 × 浅/深：Setup 预选态 + 词书列表推荐态（见 shots/r40-ui-acceptance.md）

## 5. 不做

账号、云同步、自动覆盖已选、下架精选书。
