# Round 32 · 错词池自测

**对应需求**：P1 · 错词池自测  
**前置**：错词本；R18/R22/R26/R31 四档 `quiz_variant`；今日任务「复习错词」认读  
**原则**：错词是资产——不只认读翻卡，还能用现有四档把错词测掉；不新开题型引擎

---

## 1. 目标与成功标准

自测可切换题池为**当前词书错词**（尊重单元筛选）；无错词时入口不可用并说明下一步。  
成功：开「只测错词」后题目均来自错词本；答对/答错与现错词进出规则一致；四档均可用于该池；窄窗控件不溢出。

---

## 2. 信息架构

| 入口 | 行为 |
|------|------|
| 自测顶栏 · 题池切换 | 文案 Chip / FilterChip：**全部词** \| **只测错词**（与 Segmented 义|词|听|写 同行或下一行） |
| 今日任务「复习错词」 | **本轮不改**（仍认读错词）；测错词只走自测题池开关 |
| 我的 · 错词相关 | 可选次要「去测错词」→ 切学习·自测并打开「只测错词」（有则加；无错词不展示） |

```
┌ 自测 ─────────────────┐
│ [义][词][听][写]       │
│ (全部词) (只测错词)    │  ← 题池
│ …题目…                │
└───────────────────────┘
```

---

## 3. 题池规则

- **只测错词**：候选 = 当前词书 ∩ 错词本；若已选单元筛选，再 ∩ 该单元。  
- 题量：与现自测相同上限/抽题策略，仅换池；池空则不进入作答。  
- 四档题型组装规则不变（看义/看词/听音/拼写）。  
- 答对是否移出错词本：沿用现自测答对规则（本轮不改 ProgressStore 语义）。

---

## 4. 主流程

1. 自测页默认「全部词」。  
2. 点「只测错词」：  
   - 有错词 → 选中 Chip，重建本轮题目；短 SnackBar「改测错词 · N 个」。  
   - 无错词 → Chip disabled 或点按 SnackBar「还没有错词，先去学或自测」。  
3. 切回「全部词」→ 重建；SnackBar「改测全部」。  
4. 切 Segmented 档：保持当前题池选择。  
5. 我的「去测错词」（若做）：切 Tab 学习 + 自测模式 + 打开只测错词。

---

## 5. 视觉 · 窄窗 / 全屏 / 深浅色

- 题池用 FilterChip / SegmentedButton 二选一，弱于题型 Segmented；窄窗可换行到第二行，不挤压题干。  
- 「只测错词」有数时可带小角标 N（非贴纸风，用 Chip 内数字即可）。  
- 深浅色对比足够；触控 ≥40。

---

## 6. 文案

| 键 | 文案 |
|----|------|
| 池·全部 | 全部词 |
| 池·错词 | 只测错词 |
| 切换有词 | 改测错词 · N 个 |
| 切换全部 | 改测全部 |
| 无错词 | 还没有错词，先去学或自测 |
| 我的入口 | 去测错词 |

---

## 7. 边界与空态

| 态 | 表现 |
|----|------|
| 错词=0 | 「只测错词」不可用 + 上述提示 |
| 单元筛选后错词=0 | 同上；可提示「本单元没有错词」 |
| 测到中途错词被清空 | 下一题时若池空 → 结束页或 SnackBar「错词已测完」回全部词 |
| 无当前词书 | 与现自测一致 |
