# Round 22 · 自测变体「听音选义」交互与视觉设计

**对应需求**：`docs/requirements.md` · Round 22（排 R21 后）  
**前置**：R18 看义选词；复用 `QuizEngine` / `QuizScreen`  
**原则**：补听力输入；一题一屏；TTS 失败可降级，不静默无声

---

## 1. 目标与成功标准

听系统读出的 **英文单词**，从 4 个 **中文义** 选出正确项；错词进本、选对可移出。  
成功：完成一轮听音自测；正确率可信；TTS 不可用时有提示并能退回「看中文选英文」。

---

## 2. 信息架构 / 入口

| 入口 | 行为 |
|------|------|
| 自测顶栏 Segmented | `看义选词 \| 听音选义`；记住偏好（如 `quiz_variant`） |
| 学习页/今日任务「自测」 | 用上次题型；首次默认看义 |
| 我的 · 自测本词书/单元/错词 | 同作用域；题型随偏好 |

不做独立 Tab。朗读走已有 `WordSpeaker`（英/美音全局偏好）。

```
┌ 自测 ──────────────────┐
│ 题 3/12  [看义|听音]     │
│ ┌ 🔊 再听一遍 ────────┐ │
│ │ （判分前不显示拼写）  │ │
│ └─────────────────────┘ │
│ [苹果] [香蕉] … 四选一   │
└─────────────────────────┘
```

---

## 3. 主流程

1. 组卷：复用 R18 session / 同单元干扰；播 `target.word`，选项为各词 `meaning`（去重）。
2. 进题自动朗读 1 次；「再听一遍」≥48 热区，与选项分离。
3. 点选锁定：对→浅绿 + `removeWrong` + `bumpTodayCount`；错→标红 + 正解中文 + 再播英文 + `markWrong`。
4. 判分前不露目标拼写；判分后正解行可写 `英文 · 中文`。不 `markLearned`。

---

## 4. TTS 依赖与降级

| 情况 | 行为 |
|------|------|
| speak 成功 | 正常听音题 |
| speak 抛错 / 明显失败 | SnackBar「暂时没法朗读，已改为看中文选英文」→ **整轮切回看义** |
| 无系统英文语音包 | 禁用「听音选义」段 + Tooltip「请安装系统英文语音包」 |
| 单测 | `FakeWordSpeaker`；进题断言 `speak(target.word)` |

（P0 Android SDK 验证仍独立。）

---

## 5. 视觉 · 文案 · 验收

布局：`maxWidth: 520`；选项规格同 R18；题干以大喇叭代大号中文；切题型 150ms。窄窗 Segmented 可缩字，选项保持纵向。深浅色走 `ColorScheme`。

| 键 | 文案 |
|----|------|
| 题型 | 看义选词 / 听音选义 |
| 题干 / 再听 | 听英文，选意思 / 再听一遍 |
| 无语音 | 请安装系统英文语音包后再用听音 |
| 降级 | 暂时没法朗读，已改为看中文选英文 |

- [ ] 干扰为不重复中文义；词池 <4 时 2～3 选项可用
- [ ] 自动 speak + 再听；选项不误触朗读；判分前无拼写
- [ ] 错词/今日计数同 R18；TTS 失败整轮降级或禁用听音段
- [ ] 窄窗/深浅色无溢出；analyze + FakeWordSpeaker 单测

---

## 6. 复用与不做

**复用**：组卷/`sessionCap`、作用域入口、错词进出、`bumpTodayCount`、结束页。  
**增量**：题型偏好、听音 UI、选项展示 meaning、TTS 降级。  
**不做**：听中文选英文、限时、当堂切口音、默写、云发音、排行榜。
