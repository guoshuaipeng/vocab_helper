# Round 24 · 跨词书搜索预建索引 / 缓存

**对应需求**：`docs/requirements.md` · Round 24（排 R23 后；原 P1）  
**前置**：R13 BooksScreen 跨词书搜索；`WordbookRepository.loadBook` / `_cache`  
**原则**：搜得快、结果可预期、仍本地；孩子跨教材找词，干扰少
## 0. 现状（实现事实）

`BooksScreen._onQuery`：每次输入对 catalog **逐本** `await loadBook`，对 `word`/`meaning` 做 `contains` 扫描，命中满 **40** 即停；文案「找到 N 条（最多显示 40）」。`WordbookRepository` 仅缓存整本 JSON，**无**跨书搜索索引；冷启动首搜串行加载多本（retro R13）。

## 1. 目标与成功标准

在「词书」页输入英文或中文释义，跨已装词书快速看到匹配，并一键切教材。  
成功：索引就绪后首屏结果 ≤300ms；顺序稳定；仍最多展示 40 条但不因扫库卡顿；全程本地。

## 2. 信息架构 / 入口

| 入口 | 行为 |
|------|------|
| 词书 Tab 顶栏搜索框 | 保持现位；hint「搜索英文或中文释义」 |
| 命中行 | `word` + `meaning · 词书标题`；点行 → 现有切书确认 |
| 清空 / 无字 | 退回版本分组词书列表 |

不做独立搜索 Tab；不进学习页首屏。

```
┌ 词书 ──────────────────┐
│ [更换教材 / 年级]       │
│ 🔍 搜索英文或中文释义   │
│ 找到 12 条（最多显示 40）│
│ apple 苹果 · 人教三上   │
│ apple 苹果 · 外研三上   │
└─────────────────────────┘
```

## 3. 主流程

1. **建索引**：catalog 就绪后后台预加载各书（复用 `_cache`），内存结构支持英文小写子串 + 中文释义子串 → `(bookId, word)`。
2. **就绪前**：已输入则轻量进度（沿用 `LinearProgressIndicator`），勿每键全库串行扫；就绪后同一查询自动重跑。
3. **查询**：trim + 英文 lower；稳定序（当前词书优先 → 版本/年级 → word 字典序 → bookId），截断 **40**。
4. **点命中**：走现有 `_selectBook`；已是当前词书可仅勾选/短提示。
5. **catalog 重载**：重建索引；会话内内存持有即可。

## 4. 视觉 · 窄窗 / 全屏 / 深浅色

圆角 20、elevation 0；深浅色 `ColorScheme`；窄窗不横溢；全屏勿堆统计墙；当前书可用 check / 轻 primaryContainer；动效 150～200ms。

## 5. 文案表

| 键 | 文案 |
|----|------|
| hint | 搜索英文或中文释义 |
| 有结果 | 找到 N 条（最多显示 40） |
| 无结果 | 没有匹配的单词 |
| 索引中（可选） | 正在准备搜索… |
| 切书 | 切换到这本词书？ / 取消 / 切换 |

口语对学生；不说「倒排 / 哈希」。

## 6. 边界与空态

| 态 | 处理 |
|----|------|
| 空查询 | 清 hits，显示词书目录 |
| 无匹配 | 「没有匹配的单词」+ 可清搜索 |
| 单本 load 失败 | 跳过该书，不阻断 |
| ≥40 | 截断；保留上限文案 |
| 同词多书 | 一书一行，便于选教材 |

## 7. 验收

- [ ] 索引就绪后无明显卡顿；上限 40 与文案一致  
- [ ] 英文不区分大小写子串；中文释义子串（与现对齐）  
- [ ] 当前书可识别；切书确认同 R13  
- [ ] 空态 / 无结果 / 索引未就绪有反馈；单本失败不崩  
- [ ] 窄窗 / 全屏 / 深浅色无溢出、对比足够  
- [ ] 测：建索引、截断 40、过期查询不乱序回写

## 8. 明确不做

云搜索、联网补全、语义/拼音模糊、服务端索引；搜索内开闪卡/自测（本轮只切词书）；去掉 40 上限；持久化索引文件；为搜索加账号/同步。
