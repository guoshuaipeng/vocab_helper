# Round 20 · 轻量间隔复习（1 / 3 / 7 天）交互与视觉设计

**对应需求**：P1 · 间隔复习  
**前置**：R19 今日任务（「今日待复习」挂在任务条上更自然）  
**原则**：教育有效、实现轻；不做 Anki/SM-2 全量参数

---

## 1. 学习科学（给产品的约束）

- 「认识」一次 ≠ 长期记忆；需隔日再见。  
- 对儿童：规则要可解释——「过几天再给你看一遍」，不要暴露 easiness factor。  
- 桶制：首次认识 → +1 天再入队；再认对 → +3 天；再认对 → +7 天；之后每次 +7。  
- 任一次「不认识」或自测选错 → 回到 +1 天桶，并保留/写入错词本。

---

## 2. 数据（本地）

在 `ProgressStore` 增加（示例键名，实现可微调）：

```
review_at_{wordId} → yyyy-MM-dd   // 下次应复习日
review_stage_{wordId} → 0|1|2|3  // 对应间隔 1/3/7/7
```

- 闪卡点「认识」：若无 stage，设 stage=0 且 review_at=今天+1；若已到期并再次认识，stage+1（封顶 3），按桶改期。  
- 未到期的词：**默认不进今日认读队列**（避免刚学完又刷到）。  
- 「学新词」队列 = 从未认识 ∪ 已到期待复习。  
- 我的 / 今日任务显示：`今日待复习 = review_at ≤ 今天` 的本词书词数。

---

## 3. 交互

### 3.1 认读队列变化

进入认读时排序建议：

1. 已到期复习词（旧→新）  
2. 从未学过的新词  

标题副文案：`新词 6 · 复习 4 · 剩余 10`

### 3.2 今日任务条（依赖 R19）

| 入口 | 变化 |
|------|------|
| 学新词 | 副文案改为 `新词 a · 复习 b`；b&gt;0 时入口轻微强调（小圆点） |
| （可选第四语义） | **不**单独第四按钮；复习并入学新词队列，降低决策成本 |

### 3.3 我的页

在「今日目标」卡下增加一行：

`待复习 4 个（含到期词）`  
无则：`暂无到期复习`

---

## 4. 视觉

- 不新增进度环；用已有数字+文案。  
- 复习词在闪卡正面可选极小标签 `复习`（`labelSmall` + primary 色），新词不标。  
- 标签勿用贴纸/浮动 Badge 压在插图上（本产品无插图，放在英文下方即可）。

---

## 5. 边界

| 情况 | 处理 |
|------|------|
| 清空本词书进度 | 同时清 review_at / stage |
| 自测答对 | **不**推进 stage（自测≠认读巩固）；仅错词进出 |
| 改系统日期 | 以设备本地日为准；不处理作弊 |
| 词书切换 | 计数按当前词书 id 前缀过滤 |

---

## 6. 验收

- [ ] 认识后次日出现在队列；未到期不出现  
- [ ] 不认识后 review 回到 1 天桶  
- [ ] 清空进度后无残留 review 键  
- [ ] 单测：stage 递进与日期计算  
- [ ] 文案无「SRS」「SM-2」等术语
