# Round 28 · 导出本词书已学进度（纯文本）

**对应需求**：P2 · 导出本词书已学进度  
**前置**：ProgressStore 已学 / 错词 / 今日；词书切换  
**原则**：给家长/老师可转发的纯文本；本地、无账号、无云盘强制登录

---

## 1. 目标与成功标准

在「我的」一键导出**当前词书**学习进度为纯文本，可复制或系统分享。  
成功：内容含词书名、已学数/总词数、错词数、已学词列表（可附中文）；窄窗可完成；深浅色按钮可读。

---

## 2. 信息架构

| 入口 | 行为 |
|------|------|
| 我的页 · 当前词书相关区 | 次要按钮「导出进度」（TextButton / Outlined，勿抢过清空进度） |
| 无当前词书 | 按钮 disabled + 提示「先选一本词书」 |

不做独立 Tab、PDF、Excel、邮件自动发送。

```
┌ 我的 ──────────────┐
│ 今日目标… 周视图…   │
│ [导出本词书进度]    │
│ …设置…              │
└────────────────────┘
```

---

## 3. 导出内容（纯文本）

```
单词小助手 · 进度导出
词书：{title}
日期：{yyyy-MM-dd}
已学：{learned}/{total}
错词：{wrongCount}
连续学习：{streak} 天

【已学单词】
word — meaning
…

【错词】（可空）
word — meaning
…
```

- 编码 UTF-8；换行 `\n`。  
- 已学列表按 word 字典序；错词同。  
- 未学词**不**导出（控制体积）。

---

## 4. 主流程

1. 点「导出进度」→ 生成字符串。  
2. 弹出底部 sheet / 简单对话框：预览前 8～12 行 +「复制全部」「系统分享」（有插件则用 `share_plus`；无则仅复制）。  
3. 复制成功 SnackBar「已复制到剪贴板」。  
4. 分享走系统 sheet；取消无报错。

---

## 5. 视觉 · 窄窗 / 全屏 / 深浅色

- 入口与「清空进度」同区、弱于破坏性操作（清空仍要确认；导出无需二次确认）。  
- 预览用等宽或 `bodySmall`；maxHeight 可滚。  
- 触控 ≥48；深浅色对比足够；无新 Banner。
