# Round 33 · 今日目标达成轻反馈

**对应需求**：P1 · 今日目标达成反馈  
**前置**：今日计数 `todayCount` / `dailyGoal`；我的页今日目标卡；R23 周打卡  
**原则**：达标只庆祝一次、不挡学；无勋章墙、无社交分享强迫

---

## 1. 目标与成功标准

当「今日已学」从不足跨到 ≥ 每日目标时，给孩子一次清晰、可关掉的达成反馈；我的页目标卡同步成「已完成」态。  
成功：同一自然日只触发一次；改目标后若再次从不足跨过可再触发；深浅色可读；不中断当前认读/自测操作超过一次轻提示。

---

## 2. 信息架构

| 位置 | 行为 |
|------|------|
| 学习中（认读点「认识」或自测答对导致 todayCount+1） | 若本次使 `todayCount` 从 `< goal` 变为 `≥ goal` → 弹出达成反馈 |
| 我的 · 今日目标卡 | `todayCount ≥ goal` 时展示完成态（勾 / 「今日已完成」），进度满格 |
| 周打卡 | **不改** R23 达标口径（已对齐 todayCount/dailyGoal） |

不做独立「成就」Tab、排行、补打卡。

```
┌ 轻提示 ─────────────┐
│ 今日目标达成 🎉      │  ← 单次；无循环动画
│ 已学 20 / 20         │
│ [继续]               │
└─────────────────────┘
```

---

## 3. 触发与去重

- 触发条件：写进度后 `todayCount >= dailyGoal` **且** 写前 `todayCount < dailyGoal`（上升沿）。  
- 去重键：本地 `goal_celebrated_ymd` = 当天 `yyyy-MM-dd`；已等于今天则不再弹。  
- 用户改大 `dailyGoal` 后：若当前 count 又一次从不足跨过新 goal → 允许再弹（清或改写 celebrated 逻辑：以「本 goal 值下是否已庆祝」或简单「跨沿即弹但同日最多 1 次」——**采用同日最多 1 次**，改 goal 同日不重复弹，避免刷屏）。  
- 清空本词书进度：不强制清 celebrated（日维度）；跨日自然重置。

---

## 4. 主流程

1. 学习/自测导致 today+1 且上升沿 + 今日未庆祝 → 展示反馈。  
2. 形态优先：**非模态** Material Banner 或底部轻卡片 + 主按钮「继续」（点按或 4s 后自动收）；全屏 Dialog 仅当实现更简单且可一键关。  
3. 点「继续」/自动收 → 恢复原界面，焦点仍在当前词/题。  
4. 我的页目标卡：满则勾选文案「今日已完成 · N/N」；未满保持原进度。

---

## 5. 视觉 · 窄窗 / 全屏 / 深浅色

- 反馈用 primaryContainer 浅底；标题 ≥16sp；**禁止**紫渐变、贴纸大 Badge、循环彩带动画（允许一次性 scale 150～200ms）。  
- 窄窗不挡主按钮热区超过必要；Banner 勿盖住自测底栏「下一题」。  
- 深浅色对比足够。

---

## 6. 文案

| 键 | 文案 |
|----|------|
| 标题 | 今日目标达成 |
| 副文 | 已学 {n} / {goal} |
| 按钮 | 继续 |
| 我的完成态 | 今日已完成 · {n}/{goal} |

（可用一个轻量 emoji ✅ 或 🌟，至多一处。）

---

## 7. 边界与空态

| 态 | 表现 |
|----|------|
| goal=0 或未设置 | 不触发（与现「无目标」行为一致） |
| 启动时已 ≥ goal（昨日残留同日） | 不弹；仅我的页显示完成态 |
| 自测连对跨线 | 仍只弹一次 |

---

## 8. 验收

- [ ] 上升沿触发一次；同日重复 +1 不再弹  
- [ ] 「继续」后回到原学习/自测上下文  
- [ ] 我的页完成态与计数一致  
- [ ] 窄/宽 × 深/浅截图；`docs/shots/r33-ui-acceptance.md`  
- [ ] 单测：上升沿检测 + 同日去重（假日期）
