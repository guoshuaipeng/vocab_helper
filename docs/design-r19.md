# Round 19 · 学习页「今日任务」交互与视觉设计

**对应需求**：P1 · 今日任务入口  
**前置**：R18 自测已上线（三入口才有「自测」可点）  
**原则**：打开 App 先知道「今天干什么」；不做成仪表盘；一屏一个主任务感

---

## 1. 目标

家长/孩子进入「学习」Tab 的 **3 秒内** 能回答：  
「今天还要学几词、有没有错词要复习、能不能测一下。」

---

## 2. 信息架构

在学习页 **标题与模式切换之间** 增加「今日任务」条（非独立 Tab）。

```
标题（词书名）
今日 12/20 · 连续 3 天          ← 一行状态
┌─────────┬─────────┬─────────┐
│ 学新词  │ 复习错词 │ 自测    │  ← 三个等分动作
│ 还差 8  │  5 词   │ 测一测  │
└─────────┴─────────┴─────────┘
[认读|自测] 仅在点「学新词/自测」后与下方内容联动……
单元 Chip
主内容区（闪卡或自测）
```

### 三入口行为

| 入口 | 点击后 | 角标/副文案 |
|------|--------|-------------|
| 学新词 | 模式→认读；错词复习关；若今日已达标副文案「已达标，可加练」 | `还差 max(0, goal-today)`；达标显示「加练」 |
| 复习错词 | 进入错词闪卡（全书）；无错词则 disabled | 本词书错词数；0 则灰 |
| 自测 | 模式→自测；作用域=当前单元（无则全书） | 固定「测一测」 |

**选中态**：当前正在进行的任务，对应入口用 `FilledTone` / primaryContainer 描边，避免三按钮同权重。

**与下方 `[认读|自测]` 联动**

| 点入口 | Segmented 表现 | 主内容 |
|--------|----------------|--------|
| 学新词 | 切到「认读」并可见 | 认读闪卡（非错词模式） |
| 复习错词 | **隐藏** Segmented（或禁用且文案不再抢注意） | 错词闪卡（全书） |
| 自测 | 切到「自测」并可见 | 自测内容 / 进 Quiz |

```
│ ┌──────┐ ┌──────┐ ┌──────┐  │

```

全屏：三入口 `maxWidth: 520` 内等分；不要改成四宫格或统计墙。

---

## 4. 视觉

- 入口高度 ≥ 64；圆角 16；图标可选小 `Icons.menu_book` / `replay` / `quiz`（24px），**文案为主**。  
- 禁止再套一层大 Card 包住整页；任务条可用浅 `surfaceContainerLow` 底，与闪卡 Card 分层。  
- 动效：切换任务时内容区 `AnimatedSwitcher` 200ms；入口选中色 150ms。

### 4.1 UI 打磨（实现必遵）

| 项 | 约束 |
|----|------|
| 间距 | 标题→状态行 4～8；状态行→任务条 8～12；任务条→Segmented 12；均用主题间距，禁硬编码孤立 magic number 散落 |
| 三格间隙 | 格间距 8；三格 `Expanded` 等宽，禁止固定宽度导致窄窗溢出 |
| 触控 | 单格 `minHeight: 64`；整格可点（含副文案区域），勿只点标题 |
| 选中 | 填充 `primaryContainer`，描边 1.5～2 `primary`；未选中：透明/`surface` + `outlineVariant` 细边 |
| 未选中字色 | 主文案 `onSurface`；副文案 `onSurfaceVariant` |
| 禁用（无错词） | 主/副文案与图标 → `onSurface` @ 38% 透明度；无描边强调；`IgnorePointer` 或 `onPressed: null` |
| 禁用提示 | 长按/Hover：`Tooltip`「暂无错词」；窄窗无 Hover 时，禁用格下方可跟一行 12sp `onSurfaceVariant`「暂无错词，先学新词或自测」（有错词时该行不占位） |
| 字号 | 主文案 ≥14（窄窗可压到 13）；副文案 12→窄窗 11；**禁止**折成 2×2 |
| 窄窗 ≤400 | 三格仍单行；页左右 padding 保持既有；副文案过长用「5」而非「5 词」优先保不换行 |
| 全屏 ≥900 | 主列 `maxWidth: 520` 居中；任务条不拉满整屏宽 |
| 深/浅色 | 选中态依赖 `ColorScheme`，自测对比度；禁用态勿用固定灰 `#999` |
| 防误触 | 三格紧邻但间隙 8；不与底部主按钮抢同一拇指热区（任务条在顶部信息区） |

## 5. 文案

| 键 | 文案 |
|----|------|
| 区标题（可选，省空间可省略） | 今日任务 |
| 学新词 | 学新词 |
| 复习 | 复习错词 |
| 自测 | 自测 |
| 无错词 | 暂无错词 |
| 达标 | 已达标 |
| 禁用提示（Tooltip/辅文） | 暂无错词，先学新词或自测 |

副文案优先级（窄窗保单行）：`还差 N` > `加练`；`N` 或 `N词`；自测固定 `测一测`。

## 6. 验收

- [ ] 窄窗三入口单行不折成两行堆叠（过窄时允许略缩字号至 13，不换行成 2×2）  
- [ ] 无错词时「复习」不可点，有 Tooltip 或正文提示「暂无错词…」  
- [ ] 与 R16 错词双入口不冲突：今日任务「复习错词」= 全部错词；单元错词仍留在「我的」  
- [ ] 深浅色对比足够；选中态一眼可辨，三按钮不同权  
- [ ] 点「学新词 / 自测 / 复习错词」与下方 Segmented + 主内容联动正确（复习时 Segmented 隐藏或禁用）  
- [ ] 全屏主列 ≤520 内等分，无横向溢出  
- [ ] 禁用格整格不可点；有错词后立即可点且角标数字正确
