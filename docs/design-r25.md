# Round 25 · 体验跃迁：学习页呼吸感与即时反馈

**对应需求**：用户反馈「现在像 MVP，缺交互与美感」  
**前置**：R19～R21 功能已齐；本轮**不**加新学习模式  
**原则**：少chrome、闪卡做主角、每次点按有回声；儿童向干净，不做贴纸皮肤

---

## 1. 目标与成功标准

家长/孩子打开「学习」后，应感到「这是做完的产品」而不是脚手架。

**可观察成功**
1. 首屏视觉重心在闪卡（单词区占屏高 ≥40%），任务条不再抢戏。  
2. 点「认识 / 不认识 / 翻面」有 150～220ms 状态反馈（色/微缩放），不是瞬间切词。  
3. 窄窗 ≤400、全屏 ≥900、深/浅色：无溢出、对比足够、无新增 Banner。

---

## 2. 信息架构（只调权重，不改入口）

```
词书名（轻）
今日任务条（压缩视觉重量）
[认读|自测] + 单元 Chip（可更紧）
★ 闪卡（主角：更大内边距、更清晰层级）
[不认识] [认识]
```

不做：新 Tab、勋章墙、插画包、紫渐变。

---

## 3. 视觉规格

### 3.1 今日任务条「减重」
- 外层 `surfaceContainerLow` 保留，内边距 10→8；三格 `minHeight` 64→56（仍 ≥48 触控）。  
- 未选中：去掉或极淡描边（`outlineVariant` @ 40%）；选中仍 primaryContainer + 2px primary。  
- 副文案 11sp；宽屏主文案升到 **14sp**（消化 R19 遗留）。

### 3.2 闪卡做主角
- Card：圆角 20、`elevation: 0`，浅色用 `surface` + 1px `outlineVariant`；深色用 `surfaceContainerHighest`。  
- 内边距：水平 28、垂直至少 24；单词 40sp 保持。  
- 音标：`titleMedium` + `onSurfaceVariant`（已有）。  
- 例句：16sp / 1.35（已有）；卡片内容区保持可滚动。  
- 翻面：`AnimatedSwitcher` 200ms + 轻微 `Fade+Scale(0.98→1)`，禁止炫光翻页 3D。

### 3.3 底栏按钮
- 「不认识」Outlined、「认识」Filled；竖向 padding ≥14（已有）。  
- 按下：`InkWell` 涟漪 + 可选 `scale 0.98`（150ms）。  
- 点「认识」成功：按钮/卡片边缘闪一下 `primary` 150ms 再切下一词；「不认识」用 `error` 轻闪（勿大红全屏恐吓）。

### 3.4 完成态 / 空态
- 「本轮都过完 / 今天没有新词和到期复习」：字号 20→22，副文案 `bodyMedium`，主按钮文案口语「再来一轮」「去自测一下」。  
- 空态 CTA 分流（并入原插队项）：错词空→「去学新词」；单元空→「看全部」。

## 4. 交互反馈清单

| 动作 | 反馈 |
|------|------|
| 翻卡 | 200ms switcher；提示文案可轻微淡入 |
| 认识 | 轻绿/primary 闪 → 下一词；剩余数即时更新 |
| 不认识 | 轻 error 闪 → 词入错词并重新入队尾 |
| 切单元 | 短 SnackBar（并入插队） |
| 朗读中 | 喇叭 icon 用 `primary` 短暂高亮或旋转禁用防连点 |

## 6. 验收

- [ ] 闪卡可视高度占比明显大于任务条（目视或布局断言）  
- [ ] 翻面 / 认识 / 不认识均有 ≤220ms 可见反馈  
- [ ] 任务条宽屏标题 ≥14sp；窄窗单行不折 2×2  
- [ ] 深浅色对比达标；无紫渐变/贴纸 Badge/新 Banner  
- [ ] 原插队：空态 CTA、单元 SnackBar、清空错词确认、自测底栏≥14、朗读失败 SnackBar 一并收口（能做则做）  
- [ ] 既有单测仍绿
