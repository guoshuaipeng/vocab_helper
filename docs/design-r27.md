# Round 27 · 词书「更接近全书」样板扩充

**对应需求**：P1 · 词书向更接近全书扩充  
**前置**：R21 已为 `pep-ps-3` 补音标+例句；catalog 有精选/全书体量差（小学 pep-ps-* ≈90～110 词，初中 `pep_jh_*_app` 已较满）  
**原则**：先做**一本**可验的样板，不追求全库；精选须标 source；有内容才渲染音标/例句

---

## 1. 目标与成功标准

家长选教材时能感到「词够用、来源清楚」，学习/自测/搜索命中更多真实课内词。  
成功：选定样板书词量明显接近该册课标/教材目录规模；列表与详情标明来源；新旧字段不破坏 R21/R24。

---

## 2. 本轮样板（产品定死）

| 项 | 决定 |
|----|------|
| 样板 | **`pep-ps-4`**（人教 PEP 小学四年级精选 → 扩充） |
| 理由 | 与 R21 的 `pep-ps-3` 同系列；现约 100 词，扩充空间大；避开已较满的初中 `*_app` |
| 目标词量 | **≥220**（约现有 2 倍+）；能按 unit 覆盖主要单元 |
| 字段 | 每词：`word` / `meaning` / `unit`；`phonetic`、`example` **尽量补**（新词 phonetic ≥85%，example ≥70%；专有名词可缺例） |
| source | catalog 或书内 meta：`source` 文案如「依据人教版 PEP 四年级词汇表精编/扩充」；UI 在词书卡片副文案可见 |

不做：一次扩完全部小学册；爬虫自动抓网页不经人工校对。

---

## 3. 信息架构 / UI

| 位置 | 行为 |
|------|------|
| 词书列表卡片 | 词数更新；副文案显示 source 短标（如「扩充词表」）；勿加大 Banner |
| 学习/自测/搜索 | 自动吃到新词；单元 Chip 随 unit 增多 |
| 闪卡 | 沿用 R21：空 phonetic/example 不渲染占位 |

```
┌ 人教 PEP · 四年级 ─────────┐
│ 246 词 · 扩充词表            │
│ …选书确认…                   │
└──────────────────────────────┘
```

---

## 4. 主流程（内容 + 工程）

1. 以现有 `pep-ps-4.json` 为底，按 unit 补词；去重（同 word+unit）。  
2. 补 phonetic（IPA `/…/`）、example（含目标词的完整短句）。  
3. `flutter test`：词量阈值、覆盖率、JSON 可解析；搜索索引代际（R24）不因字段增加崩溃。  
4. 手动抽查 ≥20 新词音标/例句质量。

---

## 5. 视觉与文案

- 不新开视觉风格；卡片仍 elevation 0、圆角 20。  
- 文案：「扩充词表」；详情勿写版权争议表述。  
- 窄窗/全屏/深浅色：仅词数与副文案变长，勿溢出。

---

## 6. 验收

- [ ] `pep-ps-4` 词数 ≥220；unit 分布合理（无大量空 unit）  
- [ ] 新词 phonetic ≥85% / example ≥70%（脚本可测）  
- [ ] catalog/卡片可见 source 短标  
- [ ] 学习、自测、跨书搜索抽查命中新词  
- [ ] 既有单测绿；UI 验收 `docs/shots/r27-ui-acceptance.md`（词书卡片窄/宽×深/浅）

## 7. 不做

全库批量扩充、用户可编辑词书、云端词库、付费词包、改 Tab 结构。
