# Round 23 · 我的页「连续打卡」周视图

**对应需求**：Round 23（排 R22 后；原 P2）  
**前置**：R6 今日目标；`dailyGoal` / `todayCount` / `todayGoalMet` / `streakDays`  
**原则**：看见本周哪天达标；不做社交勋章、排行、晒图

## 1. 目标与成功标准

在「我的」一眼看到本周哪几天已达标。成功：7 格态清晰；达标口径与每日目标一致；无社交压力。

## 2. 信息架构 / 入口

位置：「我的」**今日目标卡片内底部**（紧挨进度条；R20「待复习」若已上线则在其下、仍属目标卡）。

**周定义（写死）**：**自然周周一～周日**（校历习惯；非近 7 日滚动）。只展示含「今天」的那一周。

```
┌ 今日目标 ─────────────────┐
│ 今日 12/20  ═══════░      │
│ 再学 8 个就达标 · 改目标   │
│ 一 二 三 四 五 六 日       │
│ ●  ○  ●  ◐  ·  ·  ·       │
│ 已连续 3 天                │
└───────────────────────────┘
```

## 3. 达标与数据

| 概念 | 定义 |
|------|------|
| 某日达标 | `dayCount >= dailyGoal`（同 `todayGoalMet`） |
| 计数来源 | `markLearned` / `bumpTodayCount`；改目标不重算历史日 |
| 需新增 | 按日归档如 `day_count_yyyy-MM-dd`；跨日先写昨日再重置今日 |
| 上线前 | 无键过去日 → **无记录**（勿伪造达标） |

连续天数仍用 `streakDays()`，不另算第二套。

## 4. 七格状态

| 态 | 条件 | 视觉 |
|----|------|------|
| 达标 | 有记录且 count≥goal | 实心 `primary`；可选小勾 |
| 未达标 | 有记录且 count&lt;goal | 空心 `outline` |
| 无记录 | 过去日无键 | 更浅 `outlineVariant` |
| 今日进行中 | 今天且未达标 | 描边加粗；可选半填/内点 |
| 未来日 | 本周内 &gt; 今天 | 极浅占位，不可点 |

格上不标 count；Tooltip 可选 `N/目标` 或「已达标」。

## 5. 视觉 · 文案

7 格等分单行；格径≥28、热区≥40。圆角 20、elevation 0；深浅色走 `ColorScheme`。禁止贴纸 Badge / 紫渐变 / 火焰循环。达标填实 150～200ms 一次。窄窗不换行；全屏勿拉成统计墙。

| 键 | 文案 |
|----|------|
| 区标题（可省） | 本周打卡 |
| 星期 / 连续 | 一…日 / 已连续 N 天 |
| Tooltip | 已达标 / 未达标（N/目标） / 无记录 |

## 6. 验收

- [ ] 今日目标附近；周一～日 7 格单行无溢出  
- [ ] 口径 `dayCount>=dailyGoal`；改目标只影响今日态  
- [ ] 未来日不可点；无记录≠伪造达标；今日有进行中态  
- [ ] 窄窗/全屏/深浅色；与「连续天数」Stat 并存  
- [ ] 单测：跨日归档、周一/周日边界、无历史键  

## 7. 明确不做

社交勋章、排行、分享海报、补打卡；月历热力图、年度统计、自定义周起始；搬到学习页首屏；删除今日目标卡或连续天数数字。
