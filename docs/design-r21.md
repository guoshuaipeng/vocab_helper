# Round 21 · 样板词书音标 + 例句

**对应需求**：P1 · 音标+例句（先补 1 本样板）  
**前置**：模型与闪卡已支持 `phonetic` / `example`（空则不渲染）  
**原则**：内容优先于新交互；先做透 1 本

---

## 1. 目标与成功标准

- **谁**：小学/初中生跟课认读，想看怎么读、怎么用。  
- **成功**：样板书闪卡正面有可靠音标、背面有一句例句；无内容不出现空白行或「—」。  
- **可观察**：`pep-ps-3` ≥90% 非空 `phonetic`；≥80% 非空 `example`（专有名词/超短词可缺例句）。

---

## 2. 范围

| 项 | 决定 |
|----|------|
| 样板 | **`pep-ps-3`**（已有较多音标，缺口在例句）；备选 `hj-jh-7` |
| 做 | 补全/校正该 JSON 的 phonetic、example；source 注明整理来源 |
| 不做 | 一次改全库；用户可编辑；例句翻译层；音频对齐音标；新字段 |

---

## 3. 信息架构（沿用闪卡）

```
正面：word（大）→ phonetic（有则显示）→「点按卡片看中文」
背面：meaning（大）→ example（有则显示）→「点按卡片可翻回」
```

- 音标在正面（跟读）；例句在背面（用法）。  
- **自测页不展示**音标/例句（防泄题）。

---

## 4. 主流程

1. 选 `pep-ps-3` → 认读。  
2. 正面：读词 + 看音标 + 喇叭朗读英文（不读音标符号）。  
3. 翻面：中文 + 例句；过长则卡片内纵向滚动，勿裁末尾。  
4. 空字段：该行不占位（保持现有 `isNotEmpty`）。

---

## 5. 内容规范

| 字段 | 规范 |
|------|------|
| phonetic | IPA，`/…/`；英式与现有 pep 一致；空串当无 |
| example | 一句完整英文，含目标词；建议 ≤12 词；儿童向 |
| 校正 | 错音标必改；正确的勿无意义重写 |

---

## 6. 视觉（全屏 / 窄窗 / 深浅色）

- 音标：`titleMedium` + `onSurfaceVariant`；深浅色对比足够。  
- 例句：16sp、行高 1.35、居中；窄窗 ≤400px 无横向溢出。  
- 主列 `maxWidth: 520`；不加第二张卡/Banner/「已补音标」统计。

---

## 7. 文案

| 场景 | 文案 |
|------|------|
| 我的/关于（可选） | 部分词书含音标与例句 |
| 空态 | 不写「暂无音标」占位 |

---

## 8. 边界

| 情况 | 处理 |
|------|------|
| `""` / null | 不渲染 |
| 其它书仍为空 | 正常；本轮只保证样板 |
| 错词闪卡 | 同认读渲染规则 |

---

## 9. 验收

- [ ] `pep-ps-3` 抽查 ≥20 词：音标含 `/`；例句完整句；比例达上表  
- [ ] 空字段无多余空隙/占位行  
- [ ] 窄窗≤400、全屏≥900、深/浅色可读无溢出  
- [ ] 自测页无音标/例句  
- [ ] analyze / 既有测试不因 JSON 失败（词数断言则同步）

---

## 10. 明确不做

- 全库批量生成、在线 AI 补全  
- 音标分段发音、例句单独 TTS  
- 「显示音标」开关（默认有则显示）
