# Round 44 · 推荐词书沪教牛津2024七上补音标

**对应 PRD**：[prd-hj-ox-phonetic.md](prd-hj-ox-phonetic.md)（ChatPRD `ai-development-brief` 本地稿）  
**前置**：R43 学习页大词卡已支持有则显示 `phonetic`；推荐本 `hj-ox-7a-2024` 330 词 phonetic=0。  
**原则（Impeccable）**：问题=推荐本音标槽位永远空；解法=**内容补齐**，不改布局堆控件。  
**参考**：R21 pep-ps-3 `/…/` IPA；公开模式 Anki/百词斩词下音标。  
**工具**：免费 Dictionary API + UI Notes/公开模式；禁用付费 Mobbin/Refero。  
**状态**：**已完成**（UI 自验通过）

---

## 1. 目标与成功标准

- **谁**：用默认推荐本跟课的初一学生。  
- **成功**：单字词 ≥85% 有可靠英式 IPA；未揭晓大词下可见 `/…/`；短语可空。  
- **可观察**：内容单测门槛；窄浅未揭晓截图；抽查 guitar/honest 等含 `/`。

---

## 2. 信息架构 / 入口

沿用 R43 学习页（不改布局）：

```
正面：大词 → phonetic（有则显示）→「点按看中文」
背面：释义 → example（有则显示，本轮可选）
```

- 入口：选推荐本 → 认读（默认路径）。  
- **自测页不展示**音标（R21 约定，本轮回归即可）。

---

## 3. 主流程

1. 打开 hj-ox-7a-2024 → 学词。  
2. 正面读词 + 看音标（若有）+ 喇叭（读英文不读符号）。  
3. 揭晓中文；空音标不占位。

| 字段 | 规范 |
|------|------|
| phonetic | IPA，`/…/`；优先英式（ɒ/ɑː/ə）；空串当无；**禁止瞎编** |
| example | 可选；timebox 不够则砍，保音标 |
| 短语 | 含空格词 API 失败 → 保持 `""` |
