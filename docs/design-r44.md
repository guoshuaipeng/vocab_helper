# Round 44 · 自测页视觉对齐学习页（focused quiz chrome）

**对应 PRD**：[prd-iteration-rice-2026-10-23.md](prd-iteration-rice-2026-10-23.md)（RICE #1 B01；同轮小抛光 B02）  
**原则**：自测与 R43 学习同属「一个 App」——纸卡题干、细顶进度、teal 主 CTA、次要控件降噪；**不改** QuizEngine / 不增题型。  
**参考（公开模式）**：Quizlet 大卡题干；Duolingo 细进度+主色确认；Anki 少 chrome。  
**工具**：免费 only；禁用付费 Mobbin/Refero。  
**状态**：**设计就绪 · 待开发**（分析轮只文档，不写功能代码）

## 0. 方向锁

| 要 | 不要 |
|----|------|
| 题干区 **纸质抬升卡**（对齐 learn） | 默认密 Card + 顶栏仪表盘感 |

---

## 1. 目标与成功标准

从学习 overflow 进自测后，1 秒内仍感到同一视觉语言；题干是主角；主操作不可忽略。  
成功：W1–W10 自验；五档+错词池+再练回归绿；无引擎改动。

---

## 2. 信息架构 / 分区

| 区域 | 竖屏（主） | 宽屏 |
|------|------------|------|
| 顶 chrome | ≤18%：细进度 + 弱「题 i/n」；Segmented 紧凑；题池 Chip 次要 | 同左，maxWidth 520 居中可保留 |
| 题干卡 | ≥35%：纸卡；大题干（义/词/听/写各变体） | 卡不扁 |
| 选项/输入 | 中部：四选一或输入；对错态保留 | 词选义可继续 2×2 |
| 底 CTA | ≥14% 竖向 padding：teal 实心主按钮 | 同左 |

结束页：主「回学习」teal；「错题再练」outline（行为不变）。

---

## 3. 主流程（不变，仅皮）

1. 进自测 → 选档（或沿用 prefs）→ 出题。  
2. 作答 → 反馈 → teal「下一题/查看结果」。  
3. 听音/听写：判分前不露拼写；再听次要。  
4. 结束 → 回学习 / 错题再练。

---

```

│ │      苹  果              │   │  ← 大题干纸卡

│ [ apple ]  🔊                 │
```

听音：卡内大喇叭（高对比）+「再听」outline；不露英文至判分后。

- 题干字重：看义/看词 ≥28–32sp；听音以图标+短标签为主。
